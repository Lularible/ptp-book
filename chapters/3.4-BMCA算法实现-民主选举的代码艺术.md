## BMCA的核心函数

LinuxPTP的BMCA比较与状态决策主要在**bmc.c**文件里（编排则在 clock.c / port.c），bmc.c 只有**175行代码**。

### 核心函数列表

```text
bmc.c提供的函数（全部175行，一共4个函数）：

1. dscmp(struct dataset *a, struct dataset *b)          bmc.c:83-127
   - 比较两个数据集，决定哪个更适合当主时钟（IEEE 1588 规则）

2. dscmp2(struct dataset *a, struct dataset *b)         bmc.c:35-81
   - 第二阶段拓扑比较（当两个数据集的clockIdentity相同时）

3. portid_cmp(struct PortIdentity *a, struct PortIdentity *b)   bmc.c:24-33
   - 比较两个端口标识；static，只被dscmp2内部调用

4. bmc_state_decision(struct clock *c, struct port *r,
                      int (*compare)(struct dataset *, struct dataset *))   bmc.c:129-175
   - 根据BMCA结果决定端口状态；第3个参数是 c->dscmp（dscmp 或 telecom_dscmp）
```

## 数据集比较函数详解

### portid_cmp：端口标识比较

```c
/* bmc.c, 第24-33行 */

static int portid_cmp(struct PortIdentity *a, struct PortIdentity *b)
{
    int diff = memcmp(&a->clockIdentity, &b->clockIdentity, 
                      sizeof(a->clockIdentity));

    if (diff == 0) {
        diff = a->portNumber - b->portNumber;
    }

    return diff;
}
```

**返回值含义**：

```text
diff < 0：a < b（a排在前面）
diff = 0：a = b（完全相同）
diff > 0：a > b（b排在前面）
```

**比较顺序**：

```text
portid_cmp比较的是PortIdentity（clockIdentity + portNumber）：

先比较clockIdentity（8字节）：
- 如果不同，直接返回memcmp结果

如果clockIdentity相同，再比较portNumber（2字节）：
- 返回端口号的差异

这意味着：
- 同一设备的两个端口，用端口号区分
- 不同设备的端口，用clockIdentity区分
```

### dscmp：主比较函数

```c
/* bmc.c, 第83-127行 */

int dscmp(struct dataset *a, struct dataset *b)
{
    int diff;

    /* 特殊情况：同一数据集 */
    if (a == b)
        return 0;
    
    /* 特殊情况：其中一个为空 */
    if (a && !b)
        return A_BETTER;
    if (b && !a)
        return B_BETTER;

    /* 比较clockIdentity */
    diff = memcmp(&a->identity, &b->identity, sizeof(a->identity));
    if (!diff)
        return dscmp2(a, b);  /* 相同，进入第二阶段 */

    /* 比较priority1 */
    if (a->priority1 < b->priority1)
        return A_BETTER;
    if (a->priority1 > b->priority1)
        return B_BETTER;

    /* 比较clockClass */
    if (a->quality.clockClass < b->quality.clockClass)
        return A_BETTER;
    if (a->quality.clockClass > b->quality.clockClass)
        return B_BETTER;

    /* 比较clockAccuracy */
    if (a->quality.clockAccuracy < b->quality.clockAccuracy)
        return A_BETTER;
    if (a->quality.clockAccuracy > b->quality.clockAccuracy)
        return B_BETTER;

    /* 比较offsetScaledLogVariance */
    if (a->quality.offsetScaledLogVariance <
        b->quality.offsetScaledLogVariance)
        return A_BETTER;
    if (a->quality.offsetScaledLogVariance >
        b->quality.offsetScaledLogVariance)
        return B_BETTER;

    /* 比较priority2 */
    if (a->priority2 < b->priority2)
        return A_BETTER;
    if (a->priority2 > b->priority2)
        return B_BETTER;

    /* 比较clockIdentity */
    return diff < 0 ? A_BETTER : B_BETTER;
}
```

**返回值定义**：

```c
/* bmc.h */

#define A_BETTER        1   /* A更好，选择A */
#define B_BETTER       -1   /* B更好，选择B */
#define A_BETTER_TOPO   2   /* A更好（拓扑原因） */
#define B_BETTER_TOPO  -2   /* B更好（拓扑原因） */
```

**比较流程图**：

```text
dscmp比较流程（IEEE 1588-2019标准）：

┌────────────────────────────────────────┐
│ 0. 检查特殊情况                        │
│    - 同一数据集 → 0                    │
│    - 一个为空 → 选择非空的             │
├────────────────────────────────────────┤
│ 1. 预先算好identity的memcmp差值diff    │
│    （bmc.c:94，只算这一次）            │
│    - diff=0 → 立即调用dscmp2           │
│    - diff≠0 → 存下diff，继续           │
├────────────────────────────────────────┤
│ 2. 比较priority1                       │
│    - A小 → A_BETTER                    │
│    - B小 → B_BETTER                    │
│    - 相同 → 继续                       │
├────────────────────────────────────────┤
│ 3. 比较clockClass                      │
│    - A小 → A_BETTER                    │
│    - B小 → B_BETTER                    │
│    - 相同 → 继续                       │
├────────────────────────────────────────┤
│ 4. 比较clockAccuracy                   │

├────────────────────────────────────────┤
│ 7. 取用步骤1存下的diff（bmc.c:126）    │
│    - diff<0 → A_BETTER                 │
│    - diff>0 → B_BETTER                 │
└────────────────────────────────────────┘
```

**关键点**：

```text
为什么dscmp开头就先比dataset的clockIdentity？

    diff = memcmp(&a->identity, &b->identity, sizeof(a->identity));
    if (!diff)
        return dscmp2(a, b);

这里比的是 struct dataset 的 identity 成员（ClockIdentity，8字节），
不是端口标识，所以和上面 portid_cmp 的两级比较没有关系。

如果两个数据集的clockIdentity相同：
- 它们来自同一个时钟
- 需要用dscmp2进行拓扑比较
- 判断哪条路径更短（stepsRemoved、sender、receiver）

如果clockIdentity不同：
- 它们来自不同时钟
- 继续比较priority1、clockClass……priority2
- 这些都比不出胜负时，最后才用开头那个diff打破平局：
      return diff < 0 ? A_BETTER : B_BETTER;
- 也就是说diff在第1步（bmc.c:94）一次算好、在第7步（bmc.c:126）才取用，
  中间六轮比较都不再碰它
```

### dscmp2：拓扑比较函数

```c
/* bmc.c, 第35-81行 */

int dscmp2(struct dataset *a, struct dataset *b)
{
    int diff;
    unsigned int A = a->stepsRemoved, B = b->stepsRemoved;

    /* 情况1：stepsRemoved差距大于1 */
    if (A + 1 < B)
        return A_BETTER;  /* A的跳数明显少 */
    if (B + 1 < A)
        return B_BETTER;  /* B的跳数明显少 */
    /*
     * We ignore the "error-1" conditions mentioned in the
     * standard, since there is nothing we can do about it anyway.
     */
    /* 情况2：A的跳数少1 */
    if (A < B) {
        diff = portid_cmp(&b->receiver, &b->sender);
        if (diff < 0)
            return A_BETTER;
        if (diff > 0)
            return A_BETTER_TOPO;
        /* error-1 */
        return 0;
    }

    /* 情况3：B的跳数少1 */
    if (A > B) {
        diff = portid_cmp(&a->receiver, &a->sender);
        if (diff < 0)
            return B_BETTER;
        if (diff > 0)
            return B_BETTER_TOPO;
        /* error-1 */
        return 0;
    }

    /* 情况4：跳数相同，比较sender */
    diff = portid_cmp(&a->sender, &b->sender);
    if (diff < 0)
        return A_BETTER_TOPO;
    if (diff > 0)
        return B_BETTER_TOPO;

    /* 情况5：比较receiver端口号 */
    if (a->receiver.portNumber < b->receiver.portNumber)
        return A_BETTER_TOPO;
    if (a->receiver.portNumber > b->receiver.portNumber)
        return B_BETTER_TOPO;
    /*
     * If we got this far, it means "error-2" has occured.
     */
    return 0;
}
```

**拓扑比较的逻辑**：

```text
场景：同一设备的多个Announce报文（clockIdentity相同）

为什么要进行拓扑比较？

因为：
- 同一设备可能通过不同路径发送Announce
- 有些路径更短（stepsRemoved更小）
- 需要选择最短路径

步骤1：比较stepsRemoved
- 如果差距大于1，选择跳数少的
- 如果差距小于等于1，需要进一步分析

步骤2：分析拓扑关系
- 检查receiver和sender的关系
- 判断哪条路径在拓扑上更近

步骤3：比较sender和receiver
- 选择端口号小的
- 确保决策一致性
```

**图解dscmp2**：

```text
场景一：stepsRemoved差距大

网络拓扑：
主时钟 → BC1 → BC2 → 端口A（stepsRemoved = 3）
主时钟 → BC3 → 端口B（stepsRemoved = 2）

比较：
A的stepsRemoved = 3
B的stepsRemoved = 2

判断：
B + 1 = 3 = A
不满足"A + 1 < B"
但满足"B < A"

结果：B_BETTER 或 B_BETTER_TOPO（B更接近主时钟）

场景二：stepsRemoved差距小

网络拓扑：
主时钟 → BC1 → 端口A（stepsRemoved = 2）
主时钟 → BC2 → 端口A（stepsRemoved = 1）

两个Announce来自同一个端口A，但stepsRemoved不同。

如果stepsRemoved差1：
- 检查拓扑关系
- 判断哪个路径更合理
```

## 状态决策函数

### bmc_state_decision函数

```c
/* bmc.c, 第129-175行 */

enum port_state bmc_state_decision(struct clock *c, struct port *r,
                                   int (*compare)(struct dataset *a, 
                                                  struct dataset *b))
{
    struct dataset *clock_ds, *clock_best, *port_best;
    enum port_state ps;

    clock_ds = clock_default_ds(c);        /* 本时钟的数据集 */
    clock_best = clock_best_foreign(c);    /* 全局最佳外部时钟 */
    port_best = port_best_foreign(r);      /* 本端口最佳外部时钟 */
    ps = port_state(r);                    /* 当前端口状态 */

    /* 特殊情况：BMCA_NOOP模式 */
    /*
     * This scenario is particularly important in the designated_slave_fsm
     * when it is in PS_SLAVE state. In this scenario, there is no other
     * foreign master and it will elect itself as master ultimately
     * resulting in printing out some unnecessary warnings (see
     * port_slave_priority_warning()).
     */
    if (!port_best && port_bmca(r) == BMCA_NOOP) {
        return ps;
    }

    /* 特殊情况：LISTENING状态没有外部时钟 */
    if (!port_best && PS_LISTENING == ps)
        return ps;

    /* 规则M1/P1：clockClass <= 127 */
    if (clock_class(c) <= 127) {
        if (compare(clock_ds, port_best) > 0) {
            return PS_GRAND_MASTER; /* M1 */
        } else {
            return PS_PASSIVE;      /* P1 */
        }
    }

    /* 规则M2：本时钟比全局最佳更好 */
    if (compare(clock_ds, clock_best) > 0) {
        return PS_GRAND_MASTER; /* M2 */
    }

    /* 规则S1：本端口是最佳端口 */
    if (clock_best_port(c) == r) {
        return PS_SLAVE; /* S1 */
    }

    /* 规则P2/M3：比较全局最佳和端口最佳 */
    if (compare(clock_best, port_best) == A_BETTER_TOPO) {
        return PS_PASSIVE; /* P2 */
    } else {
        return PS_MASTER;  /* M3 */
    }
}
```

**IEEE 1588标准的状态决策规则**：

```text
规则M1：
- 本时钟的clockClass <= 127
- 本时钟比端口最佳外部时钟更好
- 结果：成为Grand Master

规则P1：
- 本时钟的clockClass <= 127
- 本时钟不如端口最佳外部时钟
- 结果：Passive（避免环路）

规则M2：
- 本时钟比全局最佳外部时钟更好
- 结果：成为Grand Master

规则S1：
- 本端口是全局最佳外部时钟的来源
- 结果：成为Slave

规则P2：
- 全局最佳比端口最佳拓扑更好
- 结果：Passive（环路避免）

规则M3：
- 其他情况
- 结果：成为Master
```

### 外部时钟管理函数

```c
/* v4.4的外部时钟管理在port.c实现（没有foreign.c文件） */

/* 收到Announce：添加或更新外部时钟记录（port.c:378-436，节选） */

/* Returns non-zero if the announce message is different than last. */
static int add_foreign_master(struct port *p, struct ptp_message *m)
{
    struct foreign_clock *fc;
    struct ptp_message *tmp;
    int broke_threshold = 0, diff = 0;

    /* 1. 在列表中查找已存在的外部时钟 */
    LIST_FOREACH(fc, &p->foreign_masters, list) {
        if (msg_source_equal(m, fc))
            break;
    }

    /* 2. 没找到：创建新记录。
       首条消息只记录sender，不计数 */
    if (!fc) {
        pr_notice("%s: new foreign master %s", p->log_name,
                  pid2str(&m->header.sourcePortIdentity));
        fc = malloc(sizeof(*fc));
        TAILQ_INIT(&fc->messages);
        LIST_INSERT_HEAD(&p->foreign_masters, fc, list);
        fc->port = p;
        fc->dataset.sender = m->header.sourcePortIdentity;
        return 0;
    }

    /* 3. 找到：修剪过期消息，计数加1 */
    fc_prune(fc);
    if (FOREIGN_MASTER_THRESHOLD - 1 == fc->n_messages)
        broke_threshold = 1;   /* 达到阈值(2)，需要触发状态决策 */

    /* 4. 新Announce入队 */
    msg_get(m);
    fc->n_messages++;
    TAILQ_INSERT_HEAD(&fc->messages, m, list);

    /* 5. 测试这条Announce的信息是否变了：
       队列里至少有前一条才有的可比，所以先判 n_messages > 1 */
    if (fc->n_messages > 1) {
        tmp = TAILQ_NEXT(m, list);
        diff = announce_compare(m, tmp);
    }

    /* 返回1表示"达到阈值"或"内容变化"，上层据此派发状态决策事件 */
    return broke_threshold || diff;
}
```

### 计算最佳外部时钟

```c
/* port.c中的port_compute_best（port.c:2793-2826，完整源码 + 中文旁注） */

struct foreign_clock *port_compute_best(struct port *p)
{
    int (*clk_dscmp)(struct dataset *a, struct dataset *b);
    struct foreign_clock *fc;
    struct ptp_message *tmp;

    clk_dscmp = clock_dscmp(p->clock);
    p->best = NULL;

    /* 只做服务端的端口：不参与选主，直接放弃 */
    if (p->master_only)
        return p->best;

    /* 遍历所有外部时钟 */
    LIST_FOREACH(fc, &p->foreign_masters, list) {
        tmp = TAILQ_FIRST(&fc->messages);
        if (!tmp)
            continue;

        /* 用最新一条Announce刷新dataset */
        announce_to_dataset(tmp, p, &fc->dataset);

        /* 修剪过期消息 */
        fc_prune(fc);

        /* 消息数不足阈值的跳过（消息太少不足以判定主时钟状态） */
        if (fc->n_messages < FOREIGN_MASTER_THRESHOLD)
            continue;

        if (!p->best)
            p->best = fc;
        else if (clk_dscmp(&fc->dataset, &p->best->dataset) > 0)
            p->best = fc;
        else
            fc_clear(fc);
    }

    return p->best;
}
```

### 1. Announce报文接收


### 2. 状态决策事件处理

EV_STATE_DECISION_EVENT 由clock.c的主循环处理：先置 `c->sde = 1`，poll完所有端口后调用 `handle_state_decision_event()`（clock.c:2207）：

```c
/* clock.c中的BMCA协调（clock.c:2207-2288，节选） */

static void handle_state_decision_event(struct clock *c)
{
    struct foreign_clock *best = NULL, *fc;
    struct ClockIdentity best_id;
    struct port *piter;
    int fresh_best = 0;

    /* 步骤1：各端口计算自己的最佳外部时钟，再从各端口结果里挑全局最佳 */
    LIST_FOREACH(piter, &c->ports, list) {
        fc = port_compute_best(piter);
        if (!fc)
            continue;
        if (!best || c->dscmp(&fc->dataset, &best->dataset) > 0)
            best = fc;   /* 选出全局最佳 */
    }

    /* 步骤2：best_id在这里才算出来——没有外部时钟就用本地identity
       （clock.c:2222-2226，缺这一段下面的cid_eq就成了读未初始化变量） */
    if (best) {
        best_id = best->dataset.identity;
    } else {
        best_id = c->dds.clockIdentity;
    }

    /* 步骤3：主时钟是否变化（mdiff来源） */
    if (!cid_eq(&best_id, &c->best_id) || best != c->best) {
        tsproc_reset(c->tsproc, 1);   /* 主时钟变了，重置时间戳处理器 */
        /* 省略：clock_freq_est_reset / clockcheck_reset /
           tsproc_set_delay / path_delay 等（clock.c:2229-2240） */
        fresh_best = 1;
        if (cid_eq(&best_id, &c->dds.clockIdentity))
            pr_notice("selected local clock %s as best master", cid2str(&best_id));
        else
            pr_notice("selected best master clock %s", cid2str(&best_id));
    }

    c->best = best;
    c->best_id = best_id;

    /* 步骤4：逐端口执行BMCA决策并派发状态机事件 */
    LIST_FOREACH(piter, &c->ports, list) {
        enum port_state ps;
        enum fsm_event event;
        ps = bmc_state_decision(c, piter, c->dscmp);
        switch (ps) {
        case PS_LISTENING:
            event = EV_NONE;
            break;
        case PS_GRAND_MASTER:
            pr_notice("%s: assuming the grand master role", port_log_name(piter));
            clock_update_grandmaster(c);     /* 副作用：把自己写进parentDS等 */
            event = EV_RS_GRAND_MASTER;
            break;
        case PS_MASTER:
            event = EV_RS_MASTER;
            break;
        case PS_PASSIVE:                     /* 注意源码顺序：PASSIVE在SLAVE之前 */
            event = EV_RS_PASSIVE;
            break;
        case PS_SLAVE:
            clock_update_slave(c);            /* 副作用：更新parentDS/currentDS */
            event = EV_RS_SLAVE;
            break;
        default:
            event = EV_FAULT_DETECTED;
            break;
        }
        port_dispatch(piter, event, fresh_best);  /* fresh_best即mdiff */
    }
}
```

### 3. 状态到事件转换

上面的PS→EV映射就是状态到事件的转换，**内联在clock.c的handle_state_decision_event里**（clock.c:2254-2283），没有单独的`state_to_event()`函数。注意mdiff取的是全局的`fresh_best`（主时钟是否变化），而不是逐端口计算。

## 小结：BMCA的代码智慧

**分层设计**：
- 数据集比较（dscmp/dscmp2）
- 状态决策（bmc_state_decision）
- 外部时钟管理（foreign_clock）

**函数式编程**：
- 比较函数作为参数传递
- 无副作用，易测试

**标准映射**：
- 代码逻辑与IEEE 1588规则一一对应
- 注释标注规则编号（M1、P1、S1等）

**效率优化**：
- 快速路径处理
- 避免不必要的比较
