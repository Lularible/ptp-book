## 消息格式总览

PTP消息有严格的二进制格式，必须精确编码：

```text
所有消息都以消息头开始：
┌─────────────────────────────────┐
│ Header (34 bytes)               │
└─────────────────────────────────┘

不同消息类型有不同的消息体：

Sync消息（44字节）：
┌──────────┬──────────────────────┐
│ Header   │ Origin Timestamp(10B)│
└──────────┴──────────────────────┘

Follow_Up消息（44字节）：
┌──────────┬───────────────────────────┐
│ Header   │ Precise Origin Timestamp  │
└──────────┴───────────────────────────┘

Delay_Req消息（44字节）：
┌──────────┬──────────────────────┐
│ Header   │ Origin Timestamp(10B)│
└──────────┴──────────────────────┘

Delay_Resp消息（54字节）：
┌──────────┬─────────────────┬───────────────┐
│ Header   │Receive Timestamp│ Requesting ID │
└──────────┴─────────────────┴───────────────┘

Announce消息（64字节）：
┌──────────┬─────────────┬────────────┬─────────┐
│ Header   │ Origin TS   │ UTC Offset │ ......  │
└──────────┴─────────────┴────────────┴─────────┘
```

## 公共定义

### ptp_common.h

```c
/**
 * @file ptp_common.h
 * @brief PTP common definitions and types
 *
 * Lightweight PTP implementation - educational edition
 * Supports E2E delay measurement, UDP/IPv4 transport, software timestamps
 *
 * @version 1.1.0
 * @date 2026-10-16
 */

#ifndef PTP_COMMON_H
#define PTP_COMMON_H

#include <stdint.h>
#include <time.h>
#include <endian.h>

/* Version banner, printed by both programs at start-up. Keep these in step
 * with the "Versioning" note in README.md. */
#define PTP_LITE_VERSION "1.1.0"
#define PTP_LITE_VERSION_DATE "2026-10-16"

/* Nanoseconds per second (same as linuxptp clockadj.c:30). */
#define NS_PER_SEC 1000000000LL

/* Largest value accepted for a decoded 48-bit seconds field. The field itself
 * spans 8.9 million years, but ptp_lite computes in nanoseconds: with both
 * operands under this bound every widened "(int64_t)a - (int64_t)b", and every
 * product of it with NS_PER_SEC, stays inside int64_t. Anything larger is
 * malformed or hostile and is dropped. On a 32-bit time_t the bound tightens to
 * INT32_MAX: past that "(time_t)sec" is implementation defined (gcc wraps, it
 * does not saturate), and a wrap can alias a huge offset down to a small one. */
#define PTP_MAX_VALID_SECONDS (sizeof(time_t) < 8 ? 2147483647ULL : 4294967295ULL)

/* PTP timestamp: 48-bit seconds + 32-bit nanoseconds */
typedef struct {
    uint16_t seconds_msb;    /* high 16 bits of seconds */
    uint32_t seconds_lsb;    /* low 32 bits of seconds */
    uint32_t nanoseconds;    /* nanoseconds part */
} __attribute__((packed)) ptp_timestamp_t;

/* Clock identity: 8 bytes */
typedef uint8_t ptp_clock_identity_t[8];

/* Port identity */
typedef struct {
    ptp_clock_identity_t clock_identity;
    uint16_t port_number;
} __attribute__((packed)) ptp_port_identity_t;

/* Message types */
#define PTP_MSG_SYNC           0x0
#define PTP_MSG_DELAY_REQ      0x1
#define PTP_MSG_FOLLOW_UP      0x8
#define PTP_MSG_DELAY_RESP     0x9
#define PTP_MSG_ANNOUNCE       0xB

/* PTP version */
#define PTP_VERSION            2

/* Multicast address and ports */
#define PTP_PRIMARY_MCAST      "224.0.1.129"
#define PTP_EVENT_PORT         319
#define PTP_GENERAL_PORT       320

/* Default parameters. The two *_INT values are log2(seconds), which is also
 * what goes on the wire in logMessageInterval (Table 42), so one constant
 * drives both the timer and the message field. */
#define PTP_DEFAULT_DOMAIN     0
#define PTP_DEFAULT_PRIORITY1  128
#define PTP_DEFAULT_PRIORITY2  128
#define PTP_DEFAULT_ANNOUNCE_INT  1   /* 2^1 = 2 s */
#define PTP_DEFAULT_SYNC_INT      0   /* 2^0 = 1 s */

/* currentUtcOffset carried by Announce. Published by IERS Bulletin C: it has
 * been 37 s since the leap second of 2017-01-01 and moves by +-1 s whenever a
 * leap second is inserted or deleted. No leap-second table here (that would
 * need the machinery of linuxptp lstab.c) - bump this constant by hand. */
#define PTP_CURRENT_UTC_OFFSET 37

/* Helper: convert a timespec to a PTP timestamp */
static inline void timespec_to_ptp(const struct timespec *ts,
                                   ptp_timestamp_t *ptp)
{
    uint64_t sec = (uint64_t)ts->tv_sec;
    ptp->seconds_msb = htobe16((uint16_t)(sec >> 32));
    ptp->seconds_lsb = htobe32((uint32_t)(sec & 0xFFFFFFFFULL));
    ptp->nanoseconds = htobe32((uint32_t)ts->tv_nsec);
}

/* Helper: convert a PTP timestamp to a timespec. Returns 0, or -1 when the
 * value cannot be used (seconds beyond PTP_MAX_VALID_SECONDS or nanoseconds
 * >= 1e9); the caller must then drop the whole message. */
static inline int ptp_to_timespec(const ptp_timestamp_t *ptp,
                                  struct timespec *ts)
{
    uint64_t sec  = ((uint64_t)be16toh(ptp->seconds_msb) << 32) |
                    be32toh(ptp->seconds_lsb);
    uint32_t nsec = be32toh(ptp->nanoseconds);

    if (sec > PTP_MAX_VALID_SECONDS || nsec >= (uint32_t)NS_PER_SEC) {
        return -1;
    }

    ts->tv_sec  = (time_t)sec;
    ts->tv_nsec = (long)nsec;
    return 0;
}

#endif /* PTP_COMMON_H */
```

**实现要点**：

1. **时间戳格式**：
    - 48位秒 + 32位纳秒
    - 符合IEEE 1588-2019标准
    - 使用 `__attribute__((packed))` 避免内存对齐

2. **字节序转换**：
    - PTP使用大端序（网络字节序）
    - 必须使用 `htobe16`、`htobe32` 等函数
    - 接收时使用 `be16toh`、`be32toh` 等

3. **类型安全**：
    - 使用显式类型转换，避免编译警告
    - 特别是 `uint64_t` 到 `uint16_t/uint32_t` 的转换

## 消息结构定义

### ptp_message.h（节选：省略 `:97-105` 的 `_Static_assert`，见下文「消息大小验证」）

```c
/**
 * @file ptp_message.h
 * @brief PTP message structure definitions - IEEE 1588-2019
 */

#ifndef PTP_MESSAGE_H
#define PTP_MESSAGE_H

#include <stddef.h>
#include "ptp_common.h"

/* Flag bits (IEEE 1588-2019 Table 37). The field goes on the wire as two
 * octets but ptp_header_t stores it as one uint16_t that must pass through
 * htobe16(), so a bit n of octet 0 appears here as bit (8 + n). linuxptp
 * declares "Octet flagField[2]" (msg.h:96) and plain bit values (msg.h:57-66). */
#define PTP_FLAG_TWO_STEP       0x0200U  /* octet 0.bit1 - Sync is two-step */
#define PTP_FLAG_UNICAST        0x0400U  /* octet 0.bit2 - sent to a unicast address */
#define PTP_FLAG_PTP_TIMESCALE  0x0008U  /* octet 1.bit3 - PTP timescale, not ARB */
#define PTP_FLAG_UTC_OFF_VALID  0x0004U  /* octet 1.bit2 - currentUtcOffset valid */

/* logMessageInterval value meaning "unknown / not applicable": what Table 42
 * assigns to Delay_Req, Signaling and management messages without exception. */
#define PTP_LOG_INTERVAL_NA     0x7F

/* PTP message header - IEEE 1588-2019 Table 35 (34 bytes) */
typedef struct {
    uint8_t  message_type;              /* Octet 0: message type */
    uint8_t  version_ptp;               /* Octet 1: PTP version */
    uint16_t message_length;            /* Octets 2-3: message length */
    uint8_t  domain_number;             /* Octet 4: domain number */
    /* Octet 5 is minorSdoId, not a spare field: a profile may put a value here.
     * ptp_lite implements no profile, so the all-zero value memset() leaves is
     * the correct one and a receiver must ignore it. */
    uint8_t  minor_sdoid;
    uint16_t flag_field;                /* Octets 6-7: flag field, big endian */
    uint64_t correction_field;          /* Octets 8-15: correction field, big endian */
    /* Octets 16-19 are messageTypeSpecific (Table 39): reserved for general
     * messages, available to the sender for event messages. Either way it goes
     * out as zero and the receiver ignores it. */
    uint32_t message_type_specific;
    ptp_port_identity_t source_port_identity;  /* Octets 20-29: source port ID */
    uint16_t sequence_id;               /* Octets 30-31: sequence number */
    /* Octet 32 is the legacy control field of IEEE 1588-2002, filled from
     * Table 41 (Sync 0, Delay_Req 1, Follow_Up 2, Delay_Resp 3, Management 4,
     * all others 5) and ignored by receivers. 13.3.2.13 also asks an
     * implementation without the Annex C.4.2 hardware-compatibility option to
     * transmit it as all zeros; ptp_lite keeps the Table 41 values. */
    uint8_t  control_field;
    int8_t   log_message_interval;      /* Octet 33: message interval */
} __attribute__((packed)) ptp_header_t;

/* Sync message (44 bytes) - IEEE 1588-2019 Table 44 */
typedef struct {
    ptp_header_t header;                /* 34 bytes */
    ptp_timestamp_t origin_timestamp;   /* 10 bytes */
} __attribute__((packed)) ptp_sync_msg_t;

/* Follow_Up message (44 bytes) - IEEE 1588-2019 Table 45 */
typedef struct {
    ptp_header_t header;                      /* 34 bytes */
    ptp_timestamp_t precise_origin_timestamp; /* 10 bytes */
} __attribute__((packed)) ptp_follow_up_msg_t;

/* Delay_Req message (44 bytes) - IEEE 1588-2019 Table 44 */
typedef struct {
    ptp_header_t header;                /* 34 bytes */
    ptp_timestamp_t origin_timestamp;   /* 10 bytes */
} __attribute__((packed)) ptp_delay_req_msg_t;

/* Delay_Resp message (54 bytes) - IEEE 1588-2019 Table 46 */
typedef struct {
    ptp_header_t header;                /* 34 bytes */
    ptp_timestamp_t receive_timestamp;  /* 10 bytes */
    ptp_port_identity_t requesting_port_identity; /* 10 bytes */
} __attribute__((packed)) ptp_delay_resp_msg_t;

/* Clock Quality structure (4 bytes) - IEEE 1588-2019 */
typedef struct {
    uint8_t  clock_class;                    /* Octet 0: clock class */
    uint8_t  clock_accuracy;                 /* Octet 1: clock accuracy */
    uint16_t offset_scaled_log_variance;     /* Octets 2-3: offset scaled log variance */
} __attribute__((packed)) ptp_clock_quality_t;

/* Announce message (64 bytes) - IEEE 1588-2019 Table 43 */
typedef struct {
    ptp_header_t header;                     /* 34 bytes */
    ptp_timestamp_t origin_timestamp;        /* 10 bytes */
    uint16_t current_utc_offset;             /* 2 bytes */
    uint8_t  reserved;                       /* 1 byte */
    uint8_t  grandmaster_priority1;          /* 1 byte */
    ptp_clock_quality_t grandmaster_clock_quality; /* 4 bytes */
    uint8_t  grandmaster_priority2;          /* 1 byte */
    ptp_clock_identity_t grandmaster_identity; /* 8 bytes */
    uint16_t steps_removed;                  /* 2 bytes */
    uint8_t  time_source;                    /* 1 byte */
} __attribute__((packed)) ptp_announce_msg_t;
/* Function declarations */
void ptp_init_header(ptp_header_t *hdr, uint8_t msg_type,
                     uint16_t seq_id, const ptp_port_identity_t *port_id);

/**
 * @brief Minimal inbound validation of a received message header.
 *
 * Checks what every conforming receiver must look at before acting on a
 * datagram: version, domain, the declared message_length against the size of
 * the structure the caller is about to cast to, and the number of bytes that
 * actually arrived. Without it, any host able to send 35 UDP bytes could drive
 * the clock of a ptp_lite slave.
 *
 * @param hdr    header at the start of the datagram; the caller must have
 *               received at least sizeof(ptp_header_t) bytes
 * @param len    bytes received
 * @param expect sizeof() the complete message the caller handles
 * @return NULL if the message may be processed, else a loggable reason string.
 */
const char *ptp_check_header(const ptp_header_t *hdr, size_t len,
                             size_t expect);

void ptp_init_sync(ptp_sync_msg_t *msg, uint16_t seq_id,
                   const ptp_port_identity_t *port_id);

void ptp_init_follow_up(ptp_follow_up_msg_t *msg, uint16_t seq_id,
                        const ptp_port_identity_t *port_id,
                        const struct timespec *ts);

void ptp_init_delay_req(ptp_delay_req_msg_t *msg, uint16_t seq_id,
                        const ptp_port_identity_t *port_id);

void ptp_init_delay_resp(ptp_delay_resp_msg_t *msg, uint16_t seq_id,
                         const ptp_port_identity_t *port_id,
                         const ptp_timestamp_t *ts,
                         const ptp_port_identity_t *req_port_id);
/* NOTE: seq_id must be the sequenceId of the Delay_Req being answered, read
 * back with be16toh() - a Delay_Resp echoes it, it does not count its own. */

void ptp_init_announce(ptp_announce_msg_t *msg, uint16_t seq_id,
                       const ptp_port_identity_t *port_id,
                       const struct timespec *ts);

#endif /* PTP_MESSAGE_H */
```

**实现要点**：

1. **消息头必须完整**：
   - 包含 `correction_field` (8字节)
   - 总共34字节，符合IEEE 1588-2019标准

2. **Sync和Delay_Req消息体**：
   - 使用 `origin_timestamp` 字段
   - 符合IEEE 1588标准要求

3. **Announce消息结构**：
    - 使用 `ptp_clock_quality_t` 结构体
    - 包含 `steps_removed` 字段
    - 完整的64字节

## 消息编码实现

### ptp_message.c

```c
/**
 * @file ptp_message.c
 * @brief PTP message encoding implementation - IEEE 1588-2019
 */

#include <string.h>
#include <arpa/inet.h>
#include "ptp_message.h"

void ptp_init_header(ptp_header_t *hdr, uint8_t msg_type,
                     uint16_t seq_id, const ptp_port_identity_t *port_id)
{
    memset(hdr, 0, sizeof(*hdr));

    hdr->message_type = msg_type;
    hdr->version_ptp = PTP_VERSION;
    hdr->domain_number = PTP_DEFAULT_DOMAIN;
    /* Both are multi-octet quantities, so they are written big-endian like
     * every other integer in the header, even while the value is 0. */
    hdr->flag_field = htobe16(0);
    hdr->correction_field = htobe64(0);

    memcpy(&hdr->source_port_identity, port_id, sizeof(ptp_port_identity_t));
    hdr->sequence_id = htobe16(seq_id);
    /* The per-message functions below override this where the interval is
     * meaningful (Table 42). */
    hdr->log_message_interval = PTP_LOG_INTERVAL_NA;
}

const char *ptp_check_header(const ptp_header_t *hdr, size_t len,
                             size_t expect)
{
    size_t msg_len;

    /* The caller checked that len covers the 34-byte header, so every field
     * read here arrived on the wire. */
    if (hdr->version_ptp != PTP_VERSION) {
        return "version_ptp is not PTPv2";
    }
    if (hdr->domain_number != PTP_DEFAULT_DOMAIN) {
        return "domain_number is not ours";
    }
    /* Exact on purpose: ptp_lite builds no TLVs, so a different length is one we
     * cannot decode - a peer sending AUTHENTICATION/NSM TLVs is rejected here. */
    msg_len = be16toh(hdr->message_length);
    if (msg_len != expect) {
        return "message_length does not match the type";
    }
    if (len < msg_len) {
        return "message truncated on the wire";
    }
    return NULL;
}

void ptp_init_sync(ptp_sync_msg_t *msg, uint16_t seq_id,
                   const ptp_port_identity_t *port_id)
{
    memset(msg, 0, sizeof(*msg));

    ptp_init_header(&msg->header, PTP_MSG_SYNC, seq_id, port_id);
    msg->header.message_length = htobe16(sizeof(*msg));
    /* Legacy control field, Table 41. */
    msg->header.control_field = 0;
    /* The Sync is always followed by a Follow_Up, i.e. this is two-step.
     * Without the flag a conforming slave treats the Sync as one-step, uses
     * originTimestamp (left at zero here) and throws the Follow_Up away. */
    msg->header.flag_field = htobe16(PTP_FLAG_TWO_STEP);
    msg->header.log_message_interval = PTP_DEFAULT_SYNC_INT;
}

void ptp_init_follow_up(ptp_follow_up_msg_t *msg, uint16_t seq_id,
                        const ptp_port_identity_t *port_id,
                        const struct timespec *ts)
{
    memset(msg, 0, sizeof(*msg));

    ptp_init_header(&msg->header, PTP_MSG_FOLLOW_UP, seq_id, port_id);
    msg->header.message_length = htobe16(sizeof(*msg));
    msg->header.control_field = 2;
    /* Carries the interval of the Sync sequence it belongs to. */
    msg->header.log_message_interval = PTP_DEFAULT_SYNC_INT;

    timespec_to_ptp(ts, &msg->precise_origin_timestamp);
}

void ptp_init_delay_req(ptp_delay_req_msg_t *msg, uint16_t seq_id,
                        const ptp_port_identity_t *port_id)
{
    memset(msg, 0, sizeof(*msg));

    ptp_init_header(&msg->header, PTP_MSG_DELAY_REQ, seq_id, port_id);
    msg->header.message_length = htobe16(sizeof(*msg));
    msg->header.control_field = 1;
    /* Table 42: a Delay_Req always carries 0x7F. */
    msg->header.log_message_interval = PTP_LOG_INTERVAL_NA;
}

void ptp_init_delay_resp(ptp_delay_resp_msg_t *msg, uint16_t seq_id,
                         const ptp_port_identity_t *port_id,
                         const ptp_timestamp_t *ts,
                         const ptp_port_identity_t *req_port_id)
{
    memset(msg, 0, sizeof(*msg));

    ptp_init_header(&msg->header, PTP_MSG_DELAY_RESP, seq_id, port_id);
    msg->header.message_length = htobe16(sizeof(*msg));
    msg->header.control_field = 3;
    /* Table 42: 7F fits this unicast send, which 9.5.12 does not allow - README. */
    msg->header.log_message_interval = PTP_LOG_INTERVAL_NA;

    memcpy(&msg->receive_timestamp, ts, sizeof(ptp_timestamp_t));
    memcpy(&msg->requesting_port_identity, req_port_id, sizeof(ptp_port_identity_t));
}

void ptp_init_announce(ptp_announce_msg_t *msg, uint16_t seq_id,
                       const ptp_port_identity_t *port_id,
                       const struct timespec *ts)
{
    memset(msg, 0, sizeof(*msg));

    ptp_init_header(&msg->header, PTP_MSG_ANNOUNCE, seq_id, port_id);
    msg->header.message_length = htobe16(sizeof(*msg));
    msg->header.control_field = 5;
    msg->header.log_message_interval = PTP_DEFAULT_ANNOUNCE_INT;

    timespec_to_ptp(ts, &msg->origin_timestamp);
    msg->current_utc_offset = htobe16(PTP_CURRENT_UTC_OFFSET);
    msg->grandmaster_priority1 = PTP_DEFAULT_PRIORITY1;
    memcpy(msg->grandmaster_identity, port_id->clock_identity,
           sizeof(ptp_clock_identity_t));

    /* Clock Quality - IEEE 1588-2019 7.6.3.3: all "I know nothing" values
     * (class 248 = default/no traceability, accuracy 0xFE = unknown, maximum
     * variance). Under a real BMCA this master therefore always loses to a
     * grandmaster with traceable time, which is the right outcome for an
     * oscillator-fed teaching program. */
    msg->grandmaster_clock_quality.clock_class = 248;
    msg->grandmaster_clock_quality.clock_accuracy = 0xFE;
    msg->grandmaster_clock_quality.offset_scaled_log_variance = htobe16(0xFFFF);

    msg->grandmaster_priority2 = PTP_DEFAULT_PRIORITY2;
    msg->steps_removed = htobe16(0);
    msg->time_source = 0xA0; /* Internal Oscillator */

    /* The hard-coded currentUtcOffset above is only meaningful together with
     * utcOffsetValid; ptpTimescale says the timescale is PTP and not ARB, which
     * is what makes a UTC offset apply at all (Table 37). */
    msg->header.flag_field = htobe16(PTP_FLAG_UTC_OFF_VALID |
                                     PTP_FLAG_PTP_TIMESCALE);
}
```

**实现要点**：

1. **port_number字节序转换**：
    - 必须使用 `htobe16` 转换（大端序）
    - 转换在初始化端口ID时完成：主/从时钟在 `init_port_id()` 中设置 `port_number = htobe16(1)`（`ptp_master.c:162`、`ptp_slave.c:194`）
    - `ptp_init_header` 和 `ptp_init_delay_resp` 只做 `memcpy` 拷贝，不再做转换

2. **log_message_interval**：
   - 设置为 `0x7F`（初始值）
   - 表示未知／不适用（logMessageInterval 的取值表），随后由各 `ptp_init_*` 按报文类型覆盖

3. **Announce消息的clock_quality**：
   - 完整设置三个字段
   - clock_class = 248（默认）
   - clock_accuracy = 0xFE（未知）
   - offset_scaled_log_variance = 0xFFFF
