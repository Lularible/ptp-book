## Project overview

LinuxPTP is Richard Cochran's **open-source implementation of IEEE 1588 PTP**, built for Linux.

### Core features

```text
Feature 1: native Linux support
- uses the kernel's latest timestamping API
- supports the PTP hardware clock (PHC) subsystem
- uses the SO_TIMESTAMPING socket option

Feature 2: complete protocol implementation
- ordinary clock (OC)
- boundary clock (BC)
- transparent clock (TC, both E2E and P2P)

Feature 3: several transports
- UDP/IPv4
- UDP/IPv6
- raw Ethernet (IEEE 802.3)

Feature 4: several profiles
- the default 1588 profile
- telecom profiles (G.8265.1, G.8275.1, G.8275.2)
- enterprise profile
- automotive profile

Feature 5: advanced features
- unicast operation
- authentication (AUTHENTICATION TLV)
- NetSync Monitor protocol
- IEEE 802.1AS support (end-station role)
```

### System requirements

```text
Kernel requirement: Linux 3.0 or later

Check whether the NIC supports PTP hardware timestamping:
$ ethtool -T eth0

Expected output includes:
  hardware-transmit     (SOF_TIMESTAMPING_TX_HARDWARE)
  hardware-receive      (SOF_TIMESTAMPING_RX_HARDWARE)
  hardware-raw-clock    (SOF_TIMESTAMPING_RAW_HARDWARE)
  PTP Hardware Clock: 1
```

## Core data structures

### Clock type enum

```c
/* clock.h:38-44 (verbatim; the inline comments are the book's) */

enum clock_type {
    CLOCK_TYPE_ORDINARY   = 0x8000,  /* ordinary clock */
    CLOCK_TYPE_BOUNDARY   = 0x4000,  /* boundary clock */
    CLOCK_TYPE_P2P        = 0x2000,  /* P2P transparent clock */
    CLOCK_TYPE_E2E        = 0x1000,  /* E2E transparent clock */
    CLOCK_TYPE_MANAGEMENT = 0x0800,  /* management node */
};
```

**Reading the design**:

> One correction before moving on, because this is easy to misread. The five constants are distinct powers of two (0x8000, 0x4000, 0x2000, 0x1000, 0x0800), so they look like bit masks. **linuxptp never tests them as bits.** `clock_type` is an ordinary enum. At any moment the variable `type` holds exactly one type, and the code always uses `switch` or an equality test:

```c
/* ptp4l.c:214-220 -- validate the type after reading config */
type = config_get_int(cfg, NULL, "clock_type");
switch (type) {
case CLOCK_TYPE_ORDINARY:
	if (cfg->n_interfaces > 1) {
		type = CLOCK_TYPE_BOUNDARY;
	}
	break;

/* clock.c:1103-1112 -- reject the management-node type outright */
switch (type) {
case CLOCK_TYPE_ORDINARY:
case CLOCK_TYPE_BOUNDARY:
case CLOCK_TYPE_P2P:
case CLOCK_TYPE_E2E:
	c->type = type;
	break;
case CLOCK_TYPE_MANAGEMENT:
	return NULL;
}

/* port.c:3553-3569 -- pick the dispatch/event function pair by type (excerpt) */
switch (type) {
case CLOCK_TYPE_ORDINARY:
case CLOCK_TYPE_BOUNDARY:
	p->dispatch = bc_dispatch;
	p->event = bc_event;
	break;
case CLOCK_TYPE_P2P:
	p->dispatch = p2p_dispatch;
	p->event = p2p_event;
	break;
/* the two remaining branches, e2e_dispatch / err_log_name, are in the source */
}

/* port.c:3674-3678, 3679-3683 -- equality tests, not bit tests */
if (!port_is_uds(p) && type == CLOCK_TYPE_P2P &&
    p->delayMechanism != DM_P2P) {
	pr_err("%s: P2P TC needs P2P ports", p->log_name);
	goto err_uc_service;
}
if (!port_is_uds(p) && type == CLOCK_TYPE_E2E &&
    p->delayMechanism != DM_E2E) {
	pr_err("%s: E2E TC needs E2E ports", p->log_name);
	goto err_uc_service;
}
```

The powers of two only give each enum value its own 16-bit pattern. `clock_type` has to travel as a `UInteger16` in the `CLOCK_DESCRIPTION` management attribute: `tlv.h:458` declares `UInteger16 *clockType;`, and `port.c:950` assigns `*cd->clockType = clock_type(target->clock);`. That doesn't make the values combinable.

### Port state enum

```c
/* fsm.h:24-35 (verbatim; the inline comments are the book's) */

enum port_state {
    PS_INITIALIZING = 1,    /* initializing */
    PS_FAULTY,              /* faulty */
    PS_DISABLED,            /* disabled */
    PS_LISTENING,           /* listening */
    PS_PRE_MASTER,          /* pre-master */
    PS_MASTER,              /* master */
    PS_PASSIVE,             /* passive */
    PS_UNCALIBRATED,        /* uncalibrated */
    PS_SLAVE,               /* slave */
    PS_GRAND_MASTER,        /* grand master (non-standard extension)*/
};
```

**How this maps to IEEE 1588**:

```text
The nine states IEEE 1588 defines map one-to-one onto linuxptp (fsm.h:25-33):
1. INITIALIZING      → PS_INITIALIZING
2. FAULTY            → PS_FAULTY
3. DISABLED          → PS_DISABLED
4. LISTENING         → PS_LISTENING
5. PRE_MASTER        → PS_PRE_MASTER
6. MASTER            → PS_MASTER
7. PASSIVE           → PS_PASSIVE
8. UNCALIBRATED      → PS_UNCALIBRATED
9. SLAVE             → PS_SLAVE

linuxptp's tenth state (a non-standard extension):
PS_GRAND_MASTER (fsm.h:34; the source comment reads /*non-standard extension*/)
Meaning: this clock is the root of the whole clock domain, not just a MASTER port on one path.
```

> Note: this section only lists the enum. For per-state transition rules and both state machines (`ptp_fsm` / `ptp_slave_fsm`), see **3.3**. 3.3 doesn't repeat the mapping table above.

### Servo state enum

```c
/* servo.h:44-67 (member names and order verbatim; the source has a doxygen
   comment between each pair of members, omitted here) */

enum servo_state {
    SERVO_UNLOCKED,     /* unlocked: needs more data */
    SERVO_JUMP,         /* jump: needs a large adjustment */
    SERVO_LOCKED,       /* locked: tracking */
    SERVO_LOCKED_STABLE,/* locked stable: error within threshold */
};
```

**State transition logic**:

```text
State transition flow (rewritten for clarity; line numbers point to the real source):

One thing to fix first: two layers produce the state, not a single switch --
  1. the servo-specific sample() callback reports this round's state (PI by default, pi.c:64-155);
  2. the outer servo_sample() does the counting and the "upgrade" (servo.c:116-150).

SERVO_UNLOCKED
      │
      │  PI servo, count=0: store the first sample only, still report UNLOCKED (pi.c:75-80)
      │  PI servo, count=1: two preconditions before it will estimate frequency --
      │    · the first sample must be earlier than the second, or count drops back to 0 (pi.c:86-90);
      │    · the interval must be >= 0.016/ki, capped at 1000.0 s (pi.c:92-102).
      ▼
   estimate the frequency offset drift, clamp to servo->max_frequency (pi.c:104-111)
      │
      ├── over threshold: first update and over first_step_threshold,
      │                   or over step_threshold    → SERVO_JUMP (pi.c:113-118)
      │                   the jump also resets curr_offset_values and
      │                   clears first_update to 0 (servo.c:130-133)
      │
      └── under threshold                           → SERVO_LOCKED (pi.c:119-120)
                                  (JUMP is not mandatory!)

SERVO_LOCKED
      │
      │  each sample: if |offset| < servo_offset_threshold, curr_offset_values--;
      │  one out-of-spec sample resets it to num_offset_values (servo.c:100-114).
      │  only when it reaches 0 does the state upgrade (servo.c:134-138)
      ▼
SERVO_LOCKED_STABLE
```

## Main entry point: ptp4l.c

### Overall structure

```c
/* ptp4l.c, lines 72-269. Rewritten excerpt; the real source is in that range */

int main(int argc, char *argv[])
{
    /* step 1: handle signals */                    /* ptp4l.c:81-82 */
    if (handle_term_signals())
        return -1;

    /* step 2: create the config object */          /* ptp4l.c:84-88 */
    cfg = config_create();
    if (!cfg) {
        return -1;
    }
    opts = config_long_options(cfg);   /* makes every config item a --long option */

    /* step 3: parse command-line arguments */      /* ptp4l.c:93-179 */
    while (EOF != (c = getopt_long(argc, argv, "AEP246HSLf:i:p:sl:mqvh",
                                   opts, &index))) {
        switch (c) {
            case 'A': /* auto-select delay mechanism */
            case 'E': /* E2E delay mechanism */
            case 'P': /* P2P delay mechanism */
            case '2': /* IEEE 802.3 transport */
            case '4': /* UDP/IPv4 transport */
            case '6': /* UDP/IPv6 transport */
            case 'H': /* hardware timestamping */
            case 'S': /* software timestamping */
            case 'f': /* config file */
            case 'i': /* network interface */
            /* the remaining short options L, l, p, s, m, q, v, h, the long-option
               entry case 0 and the error branch case '?': see the source */
        }
    }

    /* step 4: read the config file */              /* ptp4l.c:181-183 */
    if (config && (c = config_read(config, cfg))) {
        return c;
    }

    /* step 5: determine the clock type */          /* ptp4l.c:214-249 */
    type = config_get_int(cfg, NULL, "clock_type");
    switch (type) {
        case CLOCK_TYPE_ORDINARY:
            if (cfg->n_interfaces > 1) {
                type = CLOCK_TYPE_BOUNDARY;  /* multiple interfaces become a BC */
            }
            break;
        case CLOCK_TYPE_BOUNDARY:
            if (cfg->n_interfaces < 2) {
                fprintf(stderr, "BC needs at least two interfaces\n");
                goto out;
            }
            break;
        /* the CLOCK_TYPE_P2P / CLOCK_TYPE_E2E / CLOCK_TYPE_MANAGEMENT
           branches are at ptp4l.c:227-248 */
    }

    /* step 6: create the clock instance */         /* ptp4l.c:251-255 */
    clock = clock_create(type, cfg, req_phc);
    if (!clock) {
        fprintf(stderr, "failed to create a clock\n");
        goto out;
    }

    /* step 7: main loop */                         /* ptp4l.c:259-262 */
    while (is_running()) {
        if (clock_poll(clock))
            break;
    }

    /* step 8: clean up */                          /* ptp4l.c:263-268 */
out:
    if (clock)
        clock_destroy(clock);
    sad_destroy(cfg);
    config_destroy(cfg);

    return err;
}
```

### Design highlights

**Highlight 1: a small main program**

```text
main() is only 269 lines, and the core logic is easy to follow:
1. parse configuration (command line + config file)
2. create the clock
3. enter the main loop
4. clean up

The modularity shows:
- main() is just glue
- the core logic lives in the clock module
```

**Highlight 2: automatic type inference**

```c
/* ptp4l.c:216-220 (verbatim; the inline comment is the book's) */

case CLOCK_TYPE_ORDINARY:
	if (cfg->n_interfaces > 1) {
		type = CLOCK_TYPE_BOUNDARY;  /* automatically upgrade to boundary clock */
	}
	break;
```

```text
Smart behavior:
- the user asks for an ordinary clock
- but configures more than one interface
- it upgrades to a boundary clock

This matches the IEEE 1588 definition:
boundary clock = a PTP instance with more than one port
```

**Highlight 3: configuration precedence**

```text
Where configuration comes from, highest priority first:

1. command line
   ptp4l -i eth0 -P -H -s

2. config file
   ptp4l -f configs/default.cfg

3. defaults (lowest priority)

How it works:
- parse the command line first
- then read the config file (it fills in parameters the command line didn't set)
- anything still unset uses the default
```

## The clock module: clock.c

### Core responsibilities

```text
clock.c is responsible for:

1. clock instance management
   - create/destroy the clock
   - manage all ports
   - manage the PHC device

2. data set maintenance
   - defaultDS (the default data set)
   - currentDS (the current data set)
   - parentDS (the parent data set)
   - timePropertiesDS (the time properties data set)

3. servo control
   - create the servo instance
   - call the servo's sample callback
   - apply frequency adjustments

4. the main loop
   - poll all file descriptors
   - dispatch events to ports

5. BMCA coordination
   - collect foreign master information from all ports
   - run the global state decision
```

### The clock_create function

```c
/* clock_create(). Rewritten excerpt; the real source is clock.c:1081-1445 */

struct clock *clock_create(enum clock_type type, struct config *config,
```

### The clock_poll function

```c
/* clock_poll(). Rewritten excerpt; the real source is clock.c:1797-1886 */

int clock_poll(struct clock *c)
{
    clock_check_pollfd(c);                     /* clock.c:1805 */

    /* step 1: poll for events.
       There is no c->n_pollfd field -- the count is computed on the spot:
       nports+2 means "one per network port + two UDS ports",
       N_CLOCK_PFD = N_POLLFD + 1 (clock.c:50),
       and the extra 1 is the per-port fault timer fd */
    cnt = poll(c->pollfd, (c->nports + 2) * N_CLOCK_PFD, -1);   /* :1806 */
    if (cnt < 0) {
        if (EINTR == errno) {
            return 0;                          /* :1808-1809 */
        } else {
            pr_emerg("poll failed");
            return -1;
        }
    } else if (!cnt) {
        return 0;
    }

    cur = c->pollfd;                           /* :1818 */

    /* step 2: walk the ports.
       This is not "look up the port from the fd" either -- the port list is
       ordered, each port owns exactly N_CLOCK_PFD pollfd slots, so walk the
       list and advance cur by one slot each time */
    LIST_FOREACH(p, &c->ports, list) {         /* clock.c:1820 */
        for (i = 0; i < N_POLLFD; i++) {       /* :1822 */
            if (cur[i].revents & (POLLIN|POLLPRI|POLLERR)) {
                prior_state = port_state(p);
                if (cur[i].revents & POLLERR) {
                    /* the real code calls sk_get_error(cur[i].fd) and pr_err
                       to print the error description; see clock.c:1826-1829 */
                    event = EV_FAULT_DETECTED; /* :1825-1830 */
                } else {
                    event = port_event(p, i);  /* :1832 */
                }

                /* key: these two events only raise the SDE flag.
                   BMCA does not run here; see step 4 below */
                if (EV_STATE_DECISION_EVENT == event) {
                    c->sde = 1;                /* :1834-1836 */
                }
                if (EV_ANNOUNCE_RECEIPT_TIMEOUT_EXPIRES == event) {
                    c->sde = 1;                /* :1837-1839 */
                }

                /* hand the event to the port state machine unconditionally
                   (third argument is 0, not mdiff) */
                port_dispatch(p, event, 0);    /* :1840 */

                if ((PS_FAULTY == port_state(p)) &&
                    (prior_state != PS_FAULTY)) {
                    clock_fault_timeout(p, 1);  /* :1842-1845 */
                    break;
                }
            }
        }
        /* slot N_POLLFD of each port is the fault timer: when it expires,
           clear the fault, and dispatch EV_FAULT_CLEARED only if the link is
           up (clock.c:1849-1858) */
        cur += N_CLOCK_PFD;                    /* :1860 */
    }

    /* step 3: the two UDS management ports (clock.c:1863-1878) */
    for (i = 0; i < N_POLLFD; i++) {
        if (cur[i].revents & (POLLIN|POLLPRI)) {
            event = port_event(c->uds_rw_port, i);
            if (EV_STATE_DECISION_EVENT == event) {
                c->sde = 1;                    /* :1867-1869 */
            }
        }
    }
    cur += N_CLOCK_PFD;
    /* uds_ro_port is read-only and gets the same polling round (:1873-1877) */

    /* step 4: the real BMCA is here, deferred until the whole poll round is processed */
    if (c->sde) {                              /* clock.c:1880-1883 */
        handle_state_decision_event(c);        /* defined at clock.c:2207 */
        c->sde = 0;
    }

    clock_prune_subscriptions(c);              /* clock.c:1884 */
    return 0;
}
```

## The port module: port.c

### Core responsibilities

```text
port.c is responsible for:

1. state machine management
   - maintain the port state
   - handle state transitions
   - trigger state-related actions

2. message handling
   - receive PTP messages
   - parse message contents
   - send PTP messages

3. foreign master management
   - maintain the foreign_masters list (struct foreign_clock in foreign.h)
   - compute the best foreign master
   - handle Announce timeout

4. delay measurement
   - E2E: handle Delay_Req/Delay_Resp
   - P2P: handle Pdelay_Req/Pdelay_Resp

5. timestamp handling
   - receive timestamps
   - transmit timestamps
   - pass them to the clock module
```

### How config parsing works

```c
/* config_read(). Rewritten excerpt; the real source is config.c:819-924 */

int config_read(const char *name, struct config *cfg)   /* the parameter is name, not path */
{
    enum config_section current_section = UNKNOWN_SECTION;  /* config.c:821-827 */
    enum parser_result parser_res;
    FILE *fp;
    char buf[1024], *line, *c;            /* config.c:824 -- there is no MAX_LINE macro */
    const char *option, *value;
    struct interface *current_port = NULL;
    int line_num;

    /* "-" means read stdin, otherwise fopen */
    fp = 0 == strncmp(name, "-", 2) ? stdin : fopen(name, "r");   /* :829 */
    if (!fp) {
        fprintf(stderr, "failed to open configuration file %s: %m\n", name);
        return -1;                        /* :831-834 */
    }

    for (line_num = 1; fgets(buf, sizeof(buf), fp); line_num++) { /* :836 */
        c = buf;
        while (isspace(*c))               /* strip leading whitespace first */
            c++;
        if (*c == '#' || *c == '\n' || *c == '\0')
            continue;                     /* skip comments and blank lines, config.c:844-845 */
        line = c;
        /* …strip trailing whitespace and \n (config.c:849-852)… */

        /* three kinds of line, each with its own parse function: */

        /* 1) a section header such as [global] / [eth0] */
        if (parse_section_line(line, &current_section) == PARSED_OK) {
            /* for a [port] section, config_create_interface() also runs (:854-867) */
            continue;
        }

        /* 2) table_id / peer_address lines in a unicast master table section */
        if (current_section == UC_MTAB_SECTION) {
            if (parse_unicast_mtab_line(cfg, line, line_num))
                goto parse_error;         /* :869-874 */
            continue;
        }

        /* 3) an ordinary "option value" line: split the words, then store each item */
        if (parse_setting_line(line, &option, &value))
            goto parse_error;             /* :881-886 */
        check_deprecated_options(&option);            /* :888 */
        parser_res = parse_item(cfg, 0,
                     current_section == GLOBAL_SECTION ?
                     NULL : interface_name(current_port),
                     option, value);      /* :890-892 */
        switch (parser_res) {             /* :893-914 */
        /* five values defined in util.h:261-267 */
        case NOT_PARSED: case BAD_VALUE: case MALFORMED: case OUT_OF_RANGE:
            goto parse_error;             /* each prints its own fprintf message; see the source */
        case PARSED_OK:
            break;
        }
    }

    fclose(fp);
    return 0;                             /* config.c:917-918 */

parse_error:
    fprintf(stderr, "failed to parse configuration file %s\n", name);
    fclose(fp);
    return -2;                            /* config.c:920-923 */
}
```

## Build and install

### Compiling

```bash
# enter the source directory
cd linuxptp

# build (uses the system kernel headers by default)
make

# for a custom kernel
make KBUILD_OUTPUT=/path/to/kernel/build

# install (defaults to /usr/local)
make install

# specify an install prefix
make prefix=/opt/ptp install
```

### Running

```bash
# no -f: there is no "default config file"; everything comes from the command line and built-in defaults
ptp4l -i eth0 -S -m

# options:
# -i eth0  : use the eth0 interface
# -S       : use software timestamping
# -m       : log to stdout

# run with a config file. The repo sample configs/default.cfg has only a [global]
# section and no interface section, so -i is still required; without it you get
# "no interface specified" (ptp4l.c:208-212)
ptp4l -f configs/default.cfg -i eth0

# boundary clock
ptp4l -i eth0 -i eth1 -m

# hardware timestamping
ptp4l -i eth0 -H -m
```

## Summary: the LinuxPTP design philosophy

**Modular design**:
- core modules have clear responsibilities
- interfaces are small
- easy to extend and maintain

**Native Linux support**:
- makes full use of the kernel API
- hardware timestamping built in
- deep PHC subsystem integration

**Flexible configuration**:
- command line + config file
- support for several profiles
- a wide range of tunable parameters

**Code quality**:
- the whole source tree is about 38,500 lines (71 .c + 77 .h = 148 files)
- good comments and documentation
- follows the Linux coding style
