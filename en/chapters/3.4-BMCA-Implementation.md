# 3.4 Implementing the BMCA: The Art of the Democratic Election

## The players

The BMCA decision logic lives in a small, fast core:

| File / function | Job |
|:---|:---|
| `bmc.c` | `dscmp`, `dscmp2`, `bmc_state_decision` |
| `bmc.h` | the `A_BETTER` / `B_BETTER` return conventions |
| `foreign.h` | the foreign-master record type |
| `port.c` | `add_foreign_master`, `port_compute_best` |
| `clock.c` | `handle_state_decision_event`, the per-port rollout |

The comparison housekeeping (dscmp/dscmp2) appeared in section 3.2. The state decision and its orchestration follow.

## The state decision: bmc_state_decision (bmc.c, lines 129-175)

LinuxPTP implements the state machine decision table:

```c
/* bmc.c, lines 129-175 */

enum port_state bmc_state_decision(struct clock *c, struct port *r,
                                   int (*compare)(struct dataset *a,
                                                  struct dataset *b))
{
    struct dataset *clock_ds, *clock_best, *port_best;
    enum port_state ps;

    clock_ds   = clock_default_ds(c);
    clock_best = clock_best_foreign(c);
    port_best  = port_best_foreign(r);
    ps         = port_state(r);

    /* nothing foreign and BMCA is NOOP: stay put */
    if (!port_best && port_bmca(r) == BMCA_NOOP)
        return ps;

    /* no foreign master while LISTENING: stay */
    if (!port_best && PS_LISTENING == ps)
        return ps;

    if (clock_class(c) <= 127) {
        if (compare(clock_ds, port_best) > 0)
            return PS_GRAND_MASTER;   /* M1 */
        else
            return PS_PASSIVE;        /* P1 */
    }

    if (compare(clock_ds, clock_best) > 0)
        return PS_GRAND_MASTER;        /* M2 */

    if (clock_best_port(c) == r)
        return PS_SLAVE;               /* S1 */

    if (compare(clock_best, port_best) == A_BETTER_TOPO)
        return PS_PASSIVE;             /* P2 */
    else
        return PS_MASTER;              /* M3 */
}
```

The decisions:

| Code | Meaning | Outcome |
|:---|:---|:---|
| M1 | class ≤ 127 and local beats the best foreign | GRAND_MASTER |
| M2 | class ≥ 128 and local beats the best foreign | GRAND_MASTER |
| M3 | the port is the (tie-broken) best for this clock | MASTER |
| S1 | this port is the best slave candidate | SLAVE |
| P1 / P2 | this port must be pruned | PASSIVE |

## The state machine selection and rollout

`handle_state_decision_event(c)` (clock.c:2207) is the "big bang" that runs the election for every port:

1. Foreign master bookkeeping: each port feeds its `foreign_masters` list; `add_foreign_master` (port.c:378) counts consecutive announces from the same source and raises the state-decision event at the threshold (FOREIGN_MASTER_THRESHOLD=2) or on content change.
2. per-port `port_compute_best(p)` (port.c:2793): iterate the foreign_masters, prune stale entries, skip those below the threshold, and pick the best via dscmp:

```c
struct foreign_clock *port_compute_best(struct port *p)
{
    int (*clk_dscmp)(struct dataset *a, struct dataset *b);
    struct foreign_clock *fc;
    struct ptp_message *tmp;

    clk_dscmp = clock_dscmp(p->clock);
    p->best = NULL;

    LIST_FOREACH(fc, &p->foreign_masters, list) {
        tmp = TAILQ_FIRST(&fc->messages);
        if (!tmp) continue;
        announce_to_dataset(tmp, p, &fc->dataset);
        fc_prune(fc);
        if (fc->n_messages < FOREIGN_MASTER_THRESHOLD) continue;
        if (!p->best) p->best = fc;
        else if (clk_dscmp(&fc->dataset, &p->best->dataset) > 0)
            p->best = fc;
        else
            fc_clear(fc);
    }

    return p->best;
}
```

3. global best: `handle_state_decision_event(c)` compares the ports' Ebests, and if the grandmaster *changed* (fresh_best), resets the servo (`tsproc_reset(c->tsproc, 1)`) and logs `selected best master clock %s`.
4. rollout: for every port, run `bmc_state_decision(...)` and dispatch the matching event, atomically:

```c
LIST_FOREACH(piter, &c->ports, list) {
    ps = bmc_state_decision(c, piter, c->dscmp);
    switch (ps) {
    case PS_GRAND_MASTER: event = EV_RS_GRAND_MASTER; break;
    case PS_MASTER:       event = EV_RS_MASTER;       break;
    case PS_SLAVE:        event = EV_RS_SLAVE;        break;
    case PS_PASSIVE:      event = EV_RS_PASSIVE;      break;
    }
    port_dispatch(piter, event, fresh_best);
}
```

`fresh_best` becomes the `mdiff` that the state machine uses for its master-change transitions.

## The foreign-master record

```c
/* foreign.h */
struct foreign_clock {
    LIST_ENTRY(foreign_clock) list;                 /* list node */
    TAILQ_HEAD(messages, ptp_message) messages;     /* the announces received */
    unsigned int n_messages;                        /* foreignMasterAnnounceMessages */
    struct port *port;                              /* owning port */
    struct dataset dataset;                         /* for the BMCA comparison */
};
```

There is no separate `identity` field in v4.4: the source identity is taken from the first announce, and a fresh `dataset` is rebuilt per comparison via `announce_to_dataset()`.

## The event trigger: when to re-decide

The BMCA isn't run continuously; it is re-run when the candidate set changes:

- on the announce threshold/counter-change events (`EV_STATE_DECISION_EVENT`), sde flag in the clock;
- on announce timeout (`EV_ANNOUNCE_RECEIPT_TIMEOUT_EXPIRES`);
- when a foreign master is added or pruned.

The `handle_state_decision_event` entry (clock.c:2207) collects the bests, resets the servo on a master change, and dispatches port events, exactly the atomicity section 2.2 demanded.

## Determinism, in one sentence

The whole election is a pure function of the announce datasets (plus `dscmp`, which can be replaced by `telecom_dscmp` for the telecom profile's ranking). Identical inputs produce identical outputs, no randomness, no races.

## Summary

- `bmc.c` holds the comparison and the six decision codes.
- Foreign masters are counted per port; the best is picked by `port_compute_best`.
- A global rollout (`handle_state_decision_event`) dispatches `EV_RS_*` events, with `fresh_best` as `mdiff`.
- It is deterministic and atomic.
