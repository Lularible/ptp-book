# 3.4 Implementing the BMCA: The Art of the Democratic Election

## From Protocol to Code

In Part 2 we went through how the BMCA (best master clock algorithm) works.

## The BMCA's Core Functions

LinuxPTP's BMCA comparison and state decision live mainly in **bmc.c** (the orchestration lives in clock.c / port.c). bmc.c is only **175 lines**.

### Core Function List

```text
Functions in bmc.c (all 175 lines, four functions):

1. dscmp(struct dataset *a, struct dataset *b)          bmc.c:83-127
   - compares two datasets and decides which is the better master (IEEE 1588 rules)

2. dscmp2(struct dataset *a, struct dataset *b)         bmc.c:35-81
   - second-stage topology comparison (when both datasets share a clockIdentity)

3. portid_cmp(struct PortIdentity *a, struct PortIdentity *b)   bmc.c:24-33
   - compares two port identities; static, called only inside dscmp2

4. bmc_state_decision(struct clock *c, struct port *r,
                      int (*compare)(struct dataset *, struct dataset *))   bmc.c:129-175
   - decides the port state from the BMCA result; the third argument is c->dscmp (dscmp or telecom_dscmp)
```

## The Dataset Comparison Functions in Detail

### portid_cmp: Comparing Port Identities

```c
/* bmc.c, lines 24-33 */

static int portid_cmp(struct PortIdentity *a, struct PortIdentity *b)
{
    int diff = memcmp(&a->clockIdentity, &b->clockIdentity, 
                      sizeof(a->clockIdentity));

    if (diff == 0) {
        diff = a->portNumber - b->portNumber;
    }

    return diff;
}
```

**Return values**:

```text
diff < 0: a < b (a sorts first)
diff = 0: a = b (identical)
diff > 0: a > b (b sorts first)
```

**Comparison order**:

```text
portid_cmp compares a PortIdentity (clockIdentity + portNumber):

First compare clockIdentity (8 bytes):
- if they differ, return the memcmp result

If clockIdentity is equal, compare portNumber (2 bytes):
- return the port number difference

This means:
- two ports on the same device are told apart by port number
- ports on different devices are told apart by clockIdentity
```

### dscmp: The Main Comparison Function

```c
/* bmc.c, lines 83-127 */

int dscmp(struct dataset *a, struct dataset *b)
{
    int diff;

    /* special case: the same dataset */
    if (a == b)
        return 0;
    
    /* special case: one of them is null */
    if (a && !b)
        return A_BETTER;
    if (b && !a)
        return B_BETTER;

    /* compare clockIdentity */
    diff = memcmp(&a->identity, &b->identity, sizeof(a->identity));
    if (!diff)
        return dscmp2(a, b);  /* equal, go to stage two */

    /* compare priority1 */
    if (a->priority1 < b->priority1)
        return A_BETTER;
    if (a->priority1 > b->priority1)
        return B_BETTER;

    /* compare clockClass */
    if (a->quality.clockClass < b->quality.clockClass)
        return A_BETTER;
    if (a->quality.clockClass > b->quality.clockClass)
        return B_BETTER;

    /* compare clockAccuracy */
    if (a->quality.clockAccuracy < b->quality.clockAccuracy)
        return A_BETTER;
    if (a->quality.clockAccuracy > b->quality.clockAccuracy)
        return B_BETTER;

    /* compare offsetScaledLogVariance */
    if (a->quality.offsetScaledLogVariance <
        b->quality.offsetScaledLogVariance)
        return A_BETTER;
    if (a->quality.offsetScaledLogVariance >
        b->quality.offsetScaledLogVariance)
        return B_BETTER;

    /* compare priority2 */
    if (a->priority2 < b->priority2)
        return A_BETTER;
    if (a->priority2 > b->priority2)
        return B_BETTER;

    /* compare clockIdentity */
    return diff < 0 ? A_BETTER : B_BETTER;
}
```

**Return value definitions**:

```c
/* bmc.h */

#define A_BETTER        1   /* A is better, choose A */
#define B_BETTER       -1   /* B is better, choose B */
#define A_BETTER_TOPO   2   /* A is better (topology) */
#define B_BETTER_TOPO  -2   /* B is better (topology) */
```

**Comparison flow**:

```text
dscmp comparison flow (IEEE 1588-2019):

┌────────────────────────────────────────┐
│ 0. Check special cases                 │
│    - same dataset → 0                  │
│    - one is null → use the other       │
├────────────────────────────────────────┤
│ 1. Precompute the identity diff        │
│    (bmc.c:94, only once)               │
│    - diff=0 → call dscmp2 at once      │
│    - diff≠0 → keep diff, continue      │
├────────────────────────────────────────┤
│ 2. Compare priority1                   │
│    - A smaller → A_BETTER              │
│    - B smaller → B_BETTER              │
│    - equal → continue                  │
├────────────────────────────────────────┤
│ 3. Compare clockClass                  │
│    - A smaller → A_BETTER              │
│    - B smaller → B_BETTER              │
│    - equal → continue                  │
├────────────────────────────────────────┤
│ 4. Compare clockAccuracy               │
│    - A smaller → A_BETTER              │
│    - B smaller → B_BETTER              │
│    - equal → continue                  │
├────────────────────────────────────────┤
│ 5. Compare offsetScaledLogVariance     │
│    - A smaller → A_BETTER              │
│    - B smaller → B_BETTER              │
│    - equal → continue                  │
├────────────────────────────────────────┤
│ 6. Compare priority2                   │
│    - A smaller → A_BETTER              │
│    - B smaller → B_BETTER              │
│    - equal → continue                  │
├────────────────────────────────────────┤
│ 7. Use the step-1 diff (bmc.c:126)     │
│    - diff<0 → A_BETTER                 │
│    - diff>0 → B_BETTER                 │
└────────────────────────────────────────┘
```

**Key point**:

```text
Why does dscmp compare the dataset clockIdentity first?

    diff = memcmp(&a->identity, &b->identity, sizeof(a->identity));
    if (!diff)
        return dscmp2(a, b);

This compares the identity member of struct dataset (ClockIdentity, 8 bytes),
not the port identity, so it has nothing to do with the two-level comparison in portid_cmp above.

If two datasets have the same clockIdentity:
- they come from the same clock
- dscmp2 has to compare topology
- decide which path is shorter (stepsRemoved, sender, receiver)

If the clockIdentity differs:
- they come from different clocks
- continue with priority1, clockClass, ... priority2
- if none of these breaks the tie, the diff from the top breaks it:
      return diff < 0 ? A_BETTER : B_BETTER;
- that is, diff is computed once in step 1 (bmc.c:94) and used only in step 7 (bmc.c:126),
  and the six comparisons in between never touch it
```

### dscmp2: The Topology Comparison Function

```c
/* bmc.c, lines 35-81 */

int dscmp2(struct dataset *a, struct dataset *b)
{
    int diff;
    unsigned int A = a->stepsRemoved, B = b->stepsRemoved;

    /* case 1: the stepsRemoved gap is greater than 1 */
    if (A + 1 < B)
        return A_BETTER;  /* A has clearly fewer hops */
    if (B + 1 < A)
        return B_BETTER;  /* B has clearly fewer hops */
    /*
     * We ignore the "error-1" conditions mentioned in the
     * standard, since there is nothing we can do about it anyway.
     */
    /* case 2: A has one hop fewer */
    if (A < B) {
        diff = portid_cmp(&b->receiver, &b->sender);
        if (diff < 0)
            return A_BETTER;
        if (diff > 0)
            return A_BETTER_TOPO;
        /* error-1 */
        return 0;
    }

    /* case 3: B has one hop fewer */
    if (A > B) {
        diff = portid_cmp(&a->receiver, &a->sender);
        if (diff < 0)
            return B_BETTER;
        if (diff > 0)
            return B_BETTER_TOPO;
        /* error-1 */
        return 0;
    }

    /* case 4: same hop count, compare sender */
    diff = portid_cmp(&a->sender, &b->sender);
    if (diff < 0)
        return A_BETTER_TOPO;
    if (diff > 0)
        return B_BETTER_TOPO;

    /* case 5: compare the receiver port numbers */
    if (a->receiver.portNumber < b->receiver.portNumber)
        return A_BETTER_TOPO;
    if (a->receiver.portNumber > b->receiver.portNumber)
        return B_BETTER_TOPO;
    /*
     * If we got this far, it means "error-2" has occured.
     */
    return 0;
}
```

**The logic of the topology comparison**:

```text
Scenario: several Announce messages from the same device (same clockIdentity)

Why compare topology?

Because:
- one device can send Announce along different paths
- some paths are shorter (smaller stepsRemoved)
- you need the shortest path

Step 1: compare stepsRemoved
- if the gap is greater than 1, pick the one with fewer hops
- if the gap is 1 or less, look deeper

Step 2: analyze the topology
- check how receiver and sender relate
- decide which path is topologically closer

Step 3: compare sender and receiver
- pick the smaller port number
- keep the decision consistent
```

**dscmp2 illustrated**:

```text
Scenario 1: a large stepsRemoved gap

Network topology:
master clock → BC1 → BC2 → port A (stepsRemoved = 3)
master clock → BC3 → port B (stepsRemoved = 2)

Comparison:
A stepsRemoved = 3
B stepsRemoved = 2

Test:
B + 1 = 3 = A
does not satisfy "A + 1 < B"
but satisfies "B < A"

Result: B_BETTER or B_BETTER_TOPO (B is closer to the master clock)

Scenario 2: a small stepsRemoved gap

Network topology:
master clock → BC1 → port A (stepsRemoved = 2)
master clock → BC2 → port A (stepsRemoved = 1)

Two Announce messages from the same port A, but with different stepsRemoved.

If stepsRemoved differs by 1:
- check the topology
- decide which path makes more sense
```

## The State Decision Function

### bmc_state_decision

```c
/* bmc.c, lines 129-175 */

enum port_state bmc_state_decision(struct clock *c, struct port *r,
                                   int (*compare)(struct dataset *a, 
                                                  struct dataset *b))
{
    struct dataset *clock_ds, *clock_best, *port_best;
    enum port_state ps;

    clock_ds = clock_default_ds(c);        /* this clock's dataset */
    clock_best = clock_best_foreign(c);    /* best foreign master, global */
    port_best = port_best_foreign(r);      /* best foreign master on this port */
    ps = port_state(r);                    /* current port state */

    /* special case: BMCA_NOOP mode */
    /*
     * This scenario is particularly important in the designated_slave_fsm
     * when it is in PS_SLAVE state. In this scenario, there is no other
     * foreign master and it will elect itself as master ultimately
     * resulting in printing out some unnecessary warnings (see
     * port_slave_priority_warning()).
     */
    if (!port_best && port_bmca(r) == BMCA_NOOP) {
        return ps;
    }

    /* special case: LISTENING with no foreign master */
    if (!port_best && PS_LISTENING == ps)
        return ps;

    /* rules M1/P1: clockClass <= 127 */
    if (clock_class(c) <= 127) {
        if (compare(clock_ds, port_best) > 0) {
            return PS_GRAND_MASTER; /* M1 */
        } else {
            return PS_PASSIVE;      /* P1 */
        }
    }

    /* rule M2: this clock beats the global best */
    if (compare(clock_ds, clock_best) > 0) {
        return PS_GRAND_MASTER; /* M2 */
    }

    /* rule S1: this port is the best port */
    if (clock_best_port(c) == r) {
        return PS_SLAVE; /* S1 */
    }

    /* rules P2/M3: compare the global best and the port best */
    if (compare(clock_best, port_best) == A_BETTER_TOPO) {
        return PS_PASSIVE; /* P2 */
    } else {
        return PS_MASTER;  /* M3 */
    }
}
```

**The IEEE 1588 state decision rules**:

```text
Rule M1:
- the local clockClass is <= 127
- the local clock beats the best foreign master on the port
- result: become Grandmaster

Rule P1:
- the local clockClass is <= 127
- the local clock loses to the best foreign master on the port
- result: Passive (avoids a loop)

Rule M2:
- the local clock beats the global best foreign master
- result: become Grandmaster

Rule S1:
- this port is the source of the global best foreign master
- result: become Slave

Rule P2:
- the global best is topologically better than the port best
- result: Passive (loop avoidance)

Rule M3:
- everything else
- result: become Master
```

### Foreign Master Management Functions

```c
/* In v4.4, foreign master management lives in port.c (there is no foreign.c) */

/* On Announce: add or update a foreign master record (port.c:378-436, excerpt: omits memset(fc, 0, sizeof(*fc)) and the unicast-client validity check; the former initializes n_messages before first use) */

/* Returns non-zero if the announce message is different than last. */
static int add_foreign_master(struct port *p, struct ptp_message *m)
{
    struct foreign_clock *fc;
    struct ptp_message *tmp;
    int broke_threshold = 0, diff = 0;

    /* 1. look for an existing foreign master in the list */
    LIST_FOREACH(fc, &p->foreign_masters, list) {
        if (msg_source_equal(m, fc))
            break;
    }

    /* 2. not found: create a new record.
       The first message only records the sender, it is not counted */
    if (!fc) {
        pr_notice("%s: new foreign master %s", p->log_name,
                  pid2str(&m->header.sourcePortIdentity));
        fc = malloc(sizeof(*fc));
        TAILQ_INIT(&fc->messages);
        LIST_INSERT_HEAD(&p->foreign_masters, fc, list);
        fc->port = p;
        fc->dataset.sender = m->header.sourcePortIdentity;
        return 0;
    }

    /* 3. found: prune stale messages, bump the count */
    fc_prune(fc);
    if (FOREIGN_MASTER_THRESHOLD - 1 == fc->n_messages)
        broke_threshold = 1;   /* threshold (2) reached, need a state decision */

    /* 4. queue the new Announce */
    msg_get(m);
    fc->n_messages++;
    TAILQ_INSERT_HEAD(&fc->messages, m, list);

    /* 5. test whether this Announce carries changed information:
       there must be a previous entry to compare against, hence the n_messages > 1 guard */
    if (fc->n_messages > 1) {
        tmp = TAILQ_NEXT(m, list);
        diff = announce_compare(m, tmp);
    }

    /* a return of 1 means "threshold reached" or "content changed"; the caller dispatches a state decision event */
    return broke_threshold || diff;
}
```

### Computing the Best Foreign Master

```c
/* port_compute_best in port.c (port.c:2793-2826, full source + annotations) */

struct foreign_clock *port_compute_best(struct port *p)
{
    int (*clk_dscmp)(struct dataset *a, struct dataset *b);
    struct foreign_clock *fc;
    struct ptp_message *tmp;

    clk_dscmp = clock_dscmp(p->clock);
    p->best = NULL;

    /* a master-only port does not take part in the election; give up immediately */
    if (p->master_only)
        return p->best;

    /* walk all foreign masters */
    LIST_FOREACH(fc, &p->foreign_masters, list) {
        tmp = TAILQ_FIRST(&fc->messages);
        if (!tmp)
            continue;

        /* refresh the dataset from the latest Announce */
        announce_to_dataset(tmp, p, &fc->dataset);

        /* prune stale messages */
        fc_prune(fc);

        /* skip those below the threshold (too few messages to judge master state) */
        if (fc->n_messages < FOREIGN_MASTER_THRESHOLD)
            continue;

        if (!p->best)
            p->best = fc;
        else if (clk_dscmp(&fc->dataset, &p->best->dataset) > 0)
            p->best = fc;
        else
            fc_clear(fc);
    }

    return p->best;
}
```

## The Complete BMCA Flow

### 1. Receiving an Announce Message

```c

   it returns 1 at FOREIGN_MASTER_THRESHOLD (2) messages or on a content change */

        event = EV_STATE_DECISION_EVENT;  /* trigger a new BMCA election */

```

### 2. Handling the State Decision Event

The clock.c main loop handles EV_STATE_DECISION_EVENT: it first sets `c->sde = 1`, then after polling all ports calls `handle_state_decision_event()` (clock.c:2207):

```c
/* BMCA orchestration in clock.c (clock.c:2207-2288, excerpt: reset call ordering is simplified) */

static void handle_state_decision_event(struct clock *c)
{
    struct foreign_clock *best = NULL, *fc;
    struct ClockIdentity best_id;
    struct port *piter;
    int fresh_best = 0;

    /* step 1: each port computes its own best foreign master, then pick the global best */
    LIST_FOREACH(piter, &c->ports, list) {
        fc = port_compute_best(piter);
        if (!fc)
            continue;
        if (!best || c->dscmp(&fc->dataset, &best->dataset) > 0)
            best = fc;   /* pick the global best */
    }

    /* step 2: best_id is computed only here; with no foreign master, use the local identity
       (clock.c:2222-2226; without this block, the cid_eq below reads an uninitialized variable) */
    if (best) {
        best_id = best->dataset.identity;
    } else {
        best_id = c->dds.clockIdentity;
    }

    /* step 3: did the master change? (the source of mdiff) */
    if (!cid_eq(&best_id, &c->best_id) || best != c->best) {
        tsproc_reset(c->tsproc, 1);   /* the master changed, reset the timestamp processor */
        /* omitted: clock_freq_est_reset / clockcheck_reset /
           tsproc_set_delay / path_delay and so on (clock.c:2229-2240) */
        fresh_best = 1;
        if (cid_eq(&best_id, &c->dds.clockIdentity))
            pr_notice("selected local clock %s as best master", cid2str(&best_id));
        else
            pr_notice("selected best master clock %s", cid2str(&best_id));
    }

    c->best = best;
    c->best_id = best_id;

    /* step 4: run the BMCA decision per port and dispatch state machine events */
    LIST_FOREACH(piter, &c->ports, list) {
        enum port_state ps;
        enum fsm_event event;
        ps = bmc_state_decision(c, piter, c->dscmp);
        switch (ps) {
        case PS_LISTENING:
            event = EV_NONE;
            break;
        case PS_GRAND_MASTER:
            pr_notice("%s: assuming the grand master role", port_log_name(piter));
            clock_update_grandmaster(c);     /* side effect: writes itself into parentDS and friends */
            event = EV_RS_GRAND_MASTER;
            break;
        case PS_MASTER:
            event = EV_RS_MASTER;
            break;
        case PS_PASSIVE:                     /* note the source order: PASSIVE comes before SLAVE */
            event = EV_RS_PASSIVE;
            break;
        case PS_SLAVE:
            clock_update_slave(c);            /* side effect: updates parentDS/currentDS */
            event = EV_RS_SLAVE;
            break;
        default:
            event = EV_FAULT_DETECTED;
            break;
        }
        port_dispatch(piter, event, fresh_best);  /* fresh_best is mdiff */
    }
}
```

### 3. From State to Event

The PS→EV mapping above is the state-to-event conversion. **It is inlined in clock.c's handle_state_decision_event** (clock.c:2254-2283); there is no separate `state_to_event()` function. Note that mdiff takes the global `fresh_best` (whether the master changed), not a per-port value.

## BMCA Sequence Diagram

```text
BMCA over time:

t=0: port starts
     │
     ▼
t=1: enter INITIALIZING
     │
     ▼
t=2: initialization done, enter LISTENING
     │
     │ start the Announce receipt timeout timer
     │
     ▼
t=3: Announce arrives (from foreign master A)
     │
     │ create the foreign_clock record
     │ update the foreign master information
     │ restart the Announce receipt timeout timer
     │
     ▼
t=4: compute the best foreign master
     │
     │ compare the local clock with foreign master A
     │ decide the state (assume the local clock is better)
     │
     ▼
t=5: enter PRE_MASTER
     │
     │ start the qualification timeout timer
     │
     ▼
t=6: qualification timeout
     │
     ▼
t=7: enter MASTER/GRAND_MASTER
     │
     │ start sending Announce
     │ start sending Sync
     │

Suppose at t=10 a better foreign master arrives:

t=10: Announce arrives (from foreign master B)
      │
      │ B's priority1 < the local priority1
      │
      ▼

      │
      ▼

      │
      │ stop sending Announce
      │ start synchronizing to B
      │
      ▼

      │
      ▼
```

## Summary: The Code Wisdom of the BMCA

**Layered design**:
- dataset comparison (dscmp/dscmp2)
- state decision (bmc_state_decision)
- foreign master management (foreign_clock)

**Functional programming**:
- the comparison function is passed as an argument
- no side effects, easy to test

**Standard mapping**:
- the code logic maps one-to-one onto the IEEE 1588 rules
- comments mark the rule numbers (M1, P1, S1, etc.)

**Efficiency**:
- fast paths
- avoid unnecessary comparisons
