# 3.7 Transport Layer Implementation: The Highway for PTP Messages

## How PTP messages cross the network

The previous section showed how to drive the PHC hardware clock. That left one question:

How do PTP messages actually travel through the network?

```text
How a PTP message is born:
1. Application layer: build the PTP message (Sync, Follow_Up, Delay_Req...)
2. Transport layer: wrap it in UDP or an Ethernet frame
3. Network layer: send it to a multicast address
4. Data link layer: the NIC transmits
5. Physical layer: electrical signals on the wire

The reverse path:
5. Physical layer: receive electrical signals
4. Data link layer: the NIC receives
3. Network layer: recognize the PTP message
2. Transport layer: extract the PTP message
1. Application layer: process the contents
```

LinuxPTP supports several transports. How does it manage them all through one interface?

## The transport abstraction

### The transport_type enum

```c
/* transport.h, lines 33-42 */

enum transport_type {
    /* 0 is Reserved in spec. Use it for UDS */
    TRANS_UDS = 0,          /* Unix-domain socket (management interface) */
    TRANS_UDP_IPV4 = 1,     /* UDP/IPv4 transport */
    TRANS_UDP_IPV6,         /* UDP/IPv6 transport */
    TRANS_IEEE_802_3,       /* raw Ethernet transport */
    TRANS_DEVICENET,        /* DeviceNet (industrial protocol) */
    TRANS_CONTROLNET,       /* ControlNet (industrial protocol) */
    TRANS_PROFINET,         /* PROFINET (industrial protocol) */
};
```

**The transport types IEEE 1588 defines**:

```text
networkProtocol enumeration:

Value  Meaning                Description
0      Reserved               reserved (LinuxPTP uses it for UDS)
1      UDP/IP (IPv4)          UDP over IPv4
2      UDP/IP (IPv6)          UDP over IPv6
3      IEEE 802.3             raw Ethernet
4      DeviceNet              industrial network protocol
5      ControlNet             industrial network protocol
6      PROFINET               industrial Ethernet protocol

LinuxPTP implements the first four (0-3). The industrial protocols are not implemented.
```

### The transport_event enum

```c
/* transport.h, lines 48-54 */

enum transport_event {
    TRANS_GENERAL,      /* general messages (no timestamp needed) */
    TRANS_EVENT,        /* event messages (need a timestamp) */
    TRANS_ONESTEP,      /* one-step clock (Sync messages) */
    TRANS_P2P1STEP,     /* one-step clock (P2P delay measurement) */
    TRANS_DEFER_EVENT,  /* get the timestamp later */
};
```

**General messages vs event messages**:

```text
PTP message classes:

Event messages (need an exact timestamp):
- Sync: synchronization message
- Delay_Req: delay request
- Pdelay_Req: P2P delay request
- Pdelay_Resp: P2P delay response

Properties:
- stamped on both transmit and receive
- timestamp accuracy feeds straight into synchronization accuracy
- use the event port (319)

General messages (no exact timestamp needed):
- Follow_Up: follow-up message
- Delay_Resp: delay response
- Announce: announcement message
- Management: management message
- Signaling: signaling message

Properties:
- no exact timestamp needed
- carry the timestamp information for event messages
- use the general port (320)
```

### The transport structure

```c
/* transport_private.h, lines 29-50 */

struct transport {
    enum transport_type type;    /* transport type */
    struct config *cfg;          /* configuration object */

    /* operation function pointers */
    int (*close)(struct transport *t, struct fdarray *fda);
    int (*open)(struct transport *t, struct interface *iface,
                struct fdarray *fda, enum timestamp_type tt);
    int (*recv)(struct transport *t, int fd, void *buf, int buflen,
                struct address *addr, struct hw_timestamp *hwts);
    int (*send)(struct transport *t, struct fdarray *fda,
                enum transport_event event, int peer, void *buf, int buflen,
                struct address *addr, struct hw_timestamp *hwts);
    void (*release)(struct transport *t);
    int (*physical_addr)(struct transport *t, uint8_t *addr);
    int (*protocol_addr)(struct transport *t, uint8_t *addr);
};
```

**A textbook object-oriented design**:

```text
C's "virtual function table" pattern:

struct transport defines the interface (an abstract class)
the concrete transports (UDP, raw) implement that interface
function pointers provide polymorphism

Benefits:
- one interface for every caller
- easy to add a new transport
- upper layers don't care which transport is underneath
```

The struct holds seven function pointers and nothing else on the data path. `peer` is a parameter, not a member, and there is no `sendto` member: `transport_send`, `transport_peer`, and `transport_sendto` are wrappers in `transport.c`.

## The common interface

### transport_create: create a transport instance

```c
/* transport.c, lines 101-128 */

struct transport *transport_create(struct config *cfg, enum transport_type type)
{
    struct transport *t = NULL;
    
    switch (type) {
    case TRANS_UDS:
        t = uds_transport_create();
        break;
    case TRANS_UDP_IPV4:
        t = udp_transport_create();
        break;
    case TRANS_UDP_IPV6:
        t = udp6_transport_create();
        break;
    case TRANS_IEEE_802_3:
        t = raw_transport_create();
        break;
    case TRANS_DEVICENET:
    case TRANS_CONTROLNET:
    case TRANS_PROFINET:
        break;      /* not supported */
    }
    
    if (t) {
        t->type = type;
        t->cfg = cfg;
    }
    return t;
}
```

**Factory pattern**:

```text
transport_create is a factory function:
- creates the right instance from the type argument
- each transport has its own create function
- returns the common interface

Call examples:
t = transport_create(cfg, TRANS_UDP_IPV4);
    → calls udp_transport_create()
    → returns a UDP transport instance

t = transport_create(cfg, TRANS_IEEE_802_3);
    → calls raw_transport_create()
    → returns a raw transport instance
```

### transport_open: open a transport

```c
/* transport.c, lines 34-38 */

int transport_open(struct transport *t, struct interface *iface,

{
    return t->open(t, iface, fda, tt);
}
```

**A polymorphic call**:

```text
transport_open is a virtual call:
- calls the concrete implementation through the function pointer
- UDP: calls udp_open
- raw: calls raw_open

Arguments:
- iface: network interface configuration
- fda: file descriptor array (holds the open sockets)
- tt: timestamp type (software/hardware)

Return value:
- 0: success
- -1: failure
```

### The fdarray structure

```c
/* fd.h, lines 49-51 */

struct fdarray {
    int fd[N_POLLFD];

/* fd array index definitions, fd.h lines 31-45 */
enum {

    FD_GENERAL,            /* general message socket */

    FD_SYNC_RX_TIMER,      /* sync receive timer */
    FD_QUALIFICATION_TIMER,

    FD_UNICAST_SRV_TIMER,

    FD_RTNL,
```

**Why two sockets**:

```text
PTP needs two sockets:

FD_EVENT (event socket):
- port 319 (UDP) or EtherType 0x88F7
- sends and receives event messages
- configured for hardware timestamping

FD_GENERAL (general socket):
- port 320 (UDP)
- sends and receives general messages
- software timestamping is enough

Why split them?
- event messages need exact timestamps
- general messages don't
- separate sockets can be configured separately
```

### transport_send: send a message

```c
/* transport.c, lines 45-51 */

int transport_send(struct transport *t, struct fdarray *fda,
                   enum transport_event event, struct ptp_message *msg)
{
    int len = ntohs(msg->header.messageLength);

    return t->send(t, fda, event, 0, msg, len, NULL, &msg->hwts);
}
```

**Reading the arguments**:

```text
transport_send arguments:
- t: transport instance
- fda: socket array
- event: message class (TRANS_GENERAL/TRANS_EVENT)
- msg: PTP message structure

Internal call:
t->send(t, fda, event, 0, msg, len, NULL, &msg->hwts)
- the fourth actual argument 0 maps to the peer parameter (transport.c:50): a non-peer message (primary multicast address)
- NULL means use the default address
- &msg->hwts receives the timestamp

Message length:
ntohs(msg->header.messageLength)
- length comes from the message header
- ntohs converts the byte order
```

### transport_peer: send a peer message

```c
/* transport.c, lines 53-59 */

int transport_peer(struct transport *t, struct fdarray *fda,
                   enum transport_event event, struct ptp_message *msg)
{
    int len = ntohs(msg->header.messageLength);

    return t->send(t, fda, event, 1, msg, len, NULL, &msg->hwts);
}
```

**What peer means**:

```text
What the peer argument does (fourth parameter; transport.c:50/58/66 pass 0/1/0):
- peer=0: use the primary multicast address (ptp_dst)
- peer=1: use the peer multicast address (p2p_dst)

How each transport picks the address:
- UDP: addr_buf.sin.sin_addr = peer ? mcast_addr[MC_PDELAY] : mcast_addr[MC_PRIMARY] (udp.c:246-247)
- Ethernet: addr = peer ? &raw->p2p_addr : &raw->ptp_addr (raw.c:474)

Primary multicast address:
- used for E2E delay measurement
- carries Sync, Announce, and so on
- IPv4: 224.0.1.129
- MAC: 01:1B:19:00:00:00

Peer multicast address:
- used for P2P delay measurement
- carries Pdelay_Req, Pdelay_Resp
- IPv4: 224.0.0.107
- MAC: 01:80:C2:00:00:0E

Difference:
transport_send → primary multicast address
transport_peer → peer multicast address
```

**The ports the standard assigns**:

```text
PTP uses two UDP ports:

Port 319 (event port):
- IANA registration: ptp-event
- carries messages that need a timestamp
- configured for hardware timestamping

Port 320 (general port):
- IANA registration: ptp-general
- carries messages that don't need a timestamp
```

### Multicast address configuration

```c
/* default settings in config.c */

PORT_ITEM_STR("ptp_dst_ipv4", "224.0.1.129"),
PORT_ITEM_STR("p2p_dst_ipv4", "224.0.0.107"),
```

**Choosing the multicast address**:

```text
IPv4 multicast ranges:
224.0.0.0 - 224.0.0.255: local network control block
224.0.1.0 - 224.0.1.255: internetwork control block, which routers may forward

Only 224.0.0.0/24 is link-local.

PTP primary multicast address (224.0.1.129):
- belongs to the internetwork control block
- routers may forward it (across subnets)
- used for E2E delay measurement

PTP peer multicast address (224.0.0.107):
- belongs to the local network control block
- not forwarded, local subnet only
- used for P2P delay measurement

Why the difference?
- P2P measures adjacent nodes, so it never crosses a subnet
- E2E may cross several nodes
```

### mcast_join: join a multicast group

```c
/* udp.c, lines 63-82 */

static int mcast_join(int fd, int index, const struct sockaddr_in *sa)
{
    int err, off = 0;
    struct ip_mreqn req;

    memset(&req, 0, sizeof(req));
    memcpy(&req.imr_multiaddr, &sa->sin_addr, sizeof(struct in_addr));
    req.imr_ifindex = index;
    
    /* join the multicast group */
    err = setsockopt(fd, IPPROTO_IP, IP_ADD_MEMBERSHIP, &req, sizeof(req));
    if (err) {
        pr_err("setsockopt IP_ADD_MEMBERSHIP failed: %m");
        return -1;
    }
    
    /* disable local loopback */
    err = setsockopt(fd, IPPROTO_IP, IP_MULTICAST_LOOP, &off, sizeof(off));
    if (err) {
        pr_err("setsockopt IP_MULTICAST_LOOP failed: %m");
        return -1;
    }
    return 0;
}
```

**Joining a group in detail**:

```text
IP_ADD_MEMBERSHIP:
- joins the given multicast group
- the NIC starts accepting frames for that group address
- argument: struct ip_mreqn

struct ip_mreqn {
    struct in_addr imr_multiaddr;  /* multicast address */
    struct in_addr imr_address;    /* local address (optional) */
    int imr_ifindex;               /* interface index */
};

IP_MULTICAST_LOOP:
- controls whether we receive our own multicast
- off=0: no loopback
- stops our own messages from coming back to us
```

**Why disable loopback**:

```text
The multicast loopback problem:

Without the setting:
1. ptp4l sends a Sync message to the multicast address
2. the same NIC receives the message it just sent
3. receive timestamp and transmit timestamp are nearly identical
4. that looks like a message from another node

With loopback disabled:
- only messages from other nodes arrive
- no false reading
```

### open_socket: create a UDP socket

```c
/* udp.c, lines 91-145 */

static int open_socket(const char *name, struct in_addr mc_addr[2], short port, int ttl)
{
    struct sockaddr_in addr;
    int fd, index, on = 1;

    /* step 0: prepare the bind address before socket() (udp.c:97-100) */
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = htonl(INADDR_ANY);  /* bind every address */
    addr.sin_port = htons(port);

    /* step 1: create the socket */
    fd = socket(PF_INET, SOCK_DGRAM, IPPROTO_UDP);
    if (fd < 0) {
        pr_err("socket failed: %m");
        goto no_socket;
    }

    /* step 2: look up the interface index */
    index = sk_interface_index(fd, name);
    if (index < 0)
        goto no_option;

    /* step 3: enable address reuse */
    if (setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &on, sizeof(on))) {
        pr_err("setsockopt SO_REUSEADDR failed: %m");
        goto no_option;
    }

    /* step 4: bind the port (using the addr prepared in step 0) */
    if (bind(fd, (struct sockaddr *) &addr, sizeof(addr))) {
        pr_err("bind failed: %m");
        goto no_option;
    }

    /* step 5: bind to the given interface */
    if (setsockopt(fd, SOL_SOCKET, SO_BINDTODEVICE, name, strlen(name))) {
        pr_err("setsockopt SO_BINDTODEVICE failed: %m");
        goto no_option;
    }

    /* step 6: set the multicast TTL */
    if (setsockopt(fd, IPPROTO_IP, IP_MULTICAST_TTL, &ttl, sizeof(ttl))) {
        pr_err("setsockopt IP_MULTICAST_TTL failed: %m");
        goto no_option;
    }

    /* step 7: join two multicast groups */
    addr.sin_addr = mc_addr[0];
    if (mcast_join(fd, index, &addr)) {
        pr_err("mcast_join failed");    /* udp.c:129 */
        goto no_option;
    }
    addr.sin_addr = mc_addr[1];
    if (mcast_join(fd, index, &addr)) {
        pr_err("mcast_join failed");    /* udp.c:134 */
        goto no_option;
    }

    /* step 8: set the multicast output interface */
    if (mcast_bind(fd, index)) {
        goto no_option;
    }

    return fd;
no_option:
    close(fd);
no_socket:
    return -1;
}
```

**The eight steps of socket creation**:

```text
0. Prepare the bind address (before socket(), udp.c:97-100)
   - memset(&addr, 0, sizeof(addr))
   - sin_family = AF_INET
   - sin_addr.s_addr = htonl(INADDR_ANY)
   - sin_port = htons(port)

1. socket(PF_INET, SOCK_DGRAM, IPPROTO_UDP)
   - creates a UDP socket
   - PF_INET selects the IPv4 protocol family

2. sk_interface_index(fd, name)
   - looks up the interface index
   - needed for the multicast settings

3. SO_REUSEADDR
   - allows address reuse
   - several processes can bind the same port

4. bind(INADDR_ANY, port)
   - binds the port
   - INADDR_ANY accepts traffic for every address

5. SO_BINDTODEVICE
   - pins the socket to one interface
   - only that interface's traffic is received

6. IP_MULTICAST_TTL
   - sets the TTL of multicast messages
   - controls how far they travel

7. mcast_join (twice)
   - joins the primary group (ptp_dst)
   - joins the peer group (p2p_dst)

8. mcast_bind
   - selects the egress interface for multicast
   - sends through that interface
```

### udp_open: open the UDP transport

```c
/* udp.c, lines 151-214 */

static int udp_open(struct transport *t, struct interface *iface,
                    struct fdarray *fda, enum timestamp_type ts_type)
{
    struct udp *udp = container_of(t, struct udp, t);
    const char *name = interface_name(iface);
    uint8_t event_dscp, general_dscp;
    int efd, gfd, ttl;
    char *str;

    /* step 1: read the configuration */
    ttl = config_get_int(t->cfg, name, "udp_ttl");
    
    /* step 2: get the MAC address */
    udp->mac.len = 0;                 /* udp.c:161 */
    sk_interface_macaddr(name, &udp->mac);

    /* step 3: get the IP address */
    udp->ip.len = 0;                  /* udp.c:164 */
    sk_interface_addr(name, AF_INET, &udp->ip);

    /* step 4: parse the primary multicast address */
    str = config_get_string(t->cfg, name, "ptp_dst_ipv4");
    if (!inet_aton(str, &mcast_addr[MC_PRIMARY])) {
        pr_err("invalid ptp_dst_ipv4 %s", str);
        return -1;
    }

    /* step 5: parse the peer multicast address */
    str = config_get_string(t->cfg, name, "p2p_dst_ipv4");
    if (!inet_aton(str, &mcast_addr[MC_PDELAY])) {
        pr_err("invalid p2p_dst_ipv4 %s", str);
        return -1;
    }

    /* step 6: open the event socket */
    efd = open_socket(name, mcast_addr, EVENT_PORT, ttl);
    if (efd < 0)
        goto no_event;

    /* step 7: open the general socket */
    gfd = open_socket(name, mcast_addr, GENERAL_PORT, ttl);
    if (gfd < 0)
        goto no_general;

    /* step 8: configure timestamping */
    if (sk_timestamping_init(efd, interface_label(iface), ts_type, 
                             TRANS_UDP_IPV4, interface_get_vclock(iface)))
        goto no_timestamping;

    if (sk_general_init(gfd))
        goto no_timestamping;

    /* step 9: configure DSCP priority */
    event_dscp = config_get_int(t->cfg, NULL, "dscp_event");
    general_dscp = config_get_int(t->cfg, NULL, "dscp_general");

    if (event_dscp && sk_set_priority(efd, AF_INET, event_dscp)) {
        pr_warning("Failed to set event DSCP priority.");
    }
    if (general_dscp && sk_set_priority(gfd, AF_INET, general_dscp)) {
        pr_warning("Failed to set general DSCP priority.");
    }

    /* step 10: save the file descriptors */
    fda->fd[FD_EVENT] = efd;
    fda->fd[FD_GENERAL] = gfd;
    return 0;

no_timestamping:
    close(gfd);
no_general:
    close(efd);
no_event:
    return -1;
}
```

**DSCP priority**:

```text
DSCP (Differentiated Services Code Point):
- the quality-of-service field in the IP header
- separates traffic by priority
- high-priority traffic gets better service

PTP message priorities:
- event_dscp: event message priority
- general_dscp: general message priority

What it buys:
- event messages get high priority
- less delay variation in the network
- better synchronization accuracy

Example configuration (both are ptp4l options, 0-63; 46 is Expedited Forwarding):
dscp_event 46
dscp_general 0
```

### udp_send: send a UDP message

```c
/* udp.c, lines 222-271 */

static int udp_send(struct transport *t, struct fdarray *fda,
                    enum transport_event event, int peer, void *buf, int len,
                    struct address *addr, struct hw_timestamp *hwts)
{
    struct address addr_buf;
    unsigned char junk[1600];
    ssize_t cnt;
    int fd = -1;

    /* step 1: pick the socket */
    switch (event) {
    case TRANS_GENERAL:
        fd = fda->fd[FD_GENERAL];
        break;
    case TRANS_EVENT:
    case TRANS_ONESTEP:
    case TRANS_P2P1STEP:
    case TRANS_DEFER_EVENT:
        fd = fda->fd[FD_EVENT];
        break;
    }

    /* step 2: set the destination address */
    if (!addr) {
        memset(&addr_buf, 0, sizeof(addr_buf));
        addr_buf.sin.sin_family = AF_INET;
        addr_buf.sin.sin_addr = peer ? mcast_addr[MC_PDELAY] : 
                                       mcast_addr[MC_PRIMARY];
        addr_buf.len = sizeof(addr_buf.sin);
        addr = &addr_buf;
    }

    /* step 3: set the port */
    addr->sin.sin_port = htons(event ? EVENT_PORT : GENERAL_PORT);

    /* step 4: one-step clock special case (comments copied from the source, udp.c:254-258) */
    /*
     * Extend the payload by two, for UDP checksum correction.
     * This is not really part of the standard, but it is the way
     * that the phyter works.
     */
    if (event == TRANS_ONESTEP)
        len += 2;    /* extend for UDP checksum correction */

    /* step 5: send the message */
    cnt = sendto(fd, buf, len, 0, &addr->sa, sizeof(addr->sin));
    if (cnt < 1) {
        pr_err("sendto failed: %m");
        return -errno;
    }

    /* step 6: get the transmit timestamp (comments copied from the source, udp.c:267-269) */
    /*
     * Get the time stamp right away.
     */
    return event == TRANS_EVENT ? 
           sk_receive(fd, junk, len, NULL, hwts, MSG_ERRQUEUE) : cnt;
}
```

**Getting the transmit timestamp**:

```text
The magic of MSG_ERRQUEUE:

Ordinary socket send:
sendto(fd, buf, len, 0, &addr, sizeof(addr))
- sends the data
- returns the byte count

Getting the transmit timestamp:
sk_receive(fd, junk, len, NULL, hwts, MSG_ERRQUEUE)
- reads from the error queue
- this is not a real "receive"
- it retrieves the timestamp taken at transmit

How it works:
- the Linux kernel timestamps the packet as it leaves
- the timestamp sits in the socket's error queue
- recvmsg(MSG_ERRQUEUE) reads it back
- the junk buffer holds a copy of the sent packet
```

**The UDP extension for one-step clocks**:

```c
if (event == TRANS_ONESTEP)
    len += 2;
```

```text
One-step clocks:
- stamp the Sync at transmit time
- rewrite the timestamp field in the message
- no Follow_Up needed

The problem:
- the NIC may rewrite the timestamp only after transmit
- the UDP checksum must be recomputed
- a PHY such as the DP83640 needs two extra bytes

len += 2:
- reserves room for the UDP checksum correction
- the PHY uses those bytes to compute the checksum
```

## UDP/IPv6 transport

### IPv6 multicast addresses

**IPv6 multicast address structure**:

```text
IPv6 multicast address format:
FF0s:0:0:0:0:0:0:xxxx

FF: multicast prefix
0: flags (temporary=1, permanent=0)
s: scope:
   1: interface-local
   2: link-local
   5: site-local
   8: organization-local
   E: global

PTP primary multicast (FF0E::181):
- FF0E: permanent multicast, global scope
- 181: the PTP protocol number

PTP peer multicast (FF02::6B):
```

## Raw Ethernet transport

### Why raw Ethernet

```text
UDP vs raw Ethernet:

UDP:
- goes through the IP stack
- pays for UDP and IP headers
- subject to IP routing
- timestamps can shift when a router is in the path

Raw Ethernet:
- bypasses the IP stack
- Ethernet frames straight out
- no IP routing in the path
- steadier timestamps
- better accuracy

Where this applies:
- industrial control networks
- environments with no routing
- when you want the highest accuracy
```

**How a multicast MAC address is built**:

```text
IPv4 multicast → MAC multicast mapping:

IPv4 multicast address: 224.0.1.129
MAC multicast address: 01:00:5E:00:01:81

Mapping rule:
- first 24 bits: 01:00:5E (the IPv4 multicast MAC prefix)
- last 23 bits: the low 23 bits of the IPv4 address
- bit 25: 0 (fixed)

224.0.1.129 → 0xE0.0.1.81
take the low 23 bits → 0.01.81 (drop the top bit)
mapped MAC → 01:00:5E:00:01:81

But IEEE 1588 defines its own MAC addresses:
ptp_dst_mac: 01:1B:19:00:00:00
- not the standard mapping
- a multicast MAC reserved for IEEE 1588

p2p_dst_mac: 01:80:C2:00:00:0E
- the IEEE 802.1 bridging protocol multicast range
- a bridge address that bridges do not forward to other ports
- valid only on the local link
```

### The BPF filter

The event filter is seventeen BPF instructions long.

```c
/* raw.c, lines 131-149 (raw_filter_vlan_norm_event) */

/*
 * tcpdump -d \
 * '((ether[12:2] == 0x8100 and ether[12 + 4 :2] == 0x88F7 and ether[14+4 :1] & 0x8 != 0x8) or '\
 * ' (ether[12:2] == 0x88F7 and                                ether[14   :1] & 0x8 != 0x8)) and '\
 * 'not ether src de:ad:de:ad:be:ef'
 */

static struct sock_filter raw_filter_vlan_norm_event[] = {
    { 0x28, 0, 0, 0x0000000c },   /* ldh      [12]       */
    { 0x15, 0, 5, 0x00008100 },   /* jeq      #0x8100    */
    { 0x28, 0, 0, 0x00000010 },   /* ldh      [16]       */
    { 0x15, 0, 12, 0x000088f7 },  /* jeq      #0x88f7    */
    { 0x30, 0, 0, 0x00000012 },   /* ldb      [18]       */
    { 0x54, 0, 0, 0x00000008 },   /* and      #0x8       */
    { 0x15, 9, 4, 0x00000008 },   /* jeq      #0x8  jt=9 reject / jf=4 go to source MAC check */
    { 0x15, 0, 8, 0x000088f7 },   /* jeq      #0x88f7    */
    { 0x30, 0, 0, 0x0000000e },   /* ldb      [14]       */
    { 0x54, 0, 0, 0x00000008 },   /* and      #0x8       */
    { 0x15, 5, 0, 0x00000008 },   /* jeq      #0x8  jt=5 reject / jf=0 continue to source MAC check */
    { 0x20, 0, 0, 0x00000008 },   /* ld       [8]        */
    { 0x15, 0, 2, 0xdeadbeef },   /* jeq      #0xdeadbeef */
    { 0x28, 0, 0, 0x00000006 },   /* ldh      [6]        */
    { 0x15, 1, 0, 0x0000dead },   /* jeq      #0xdead    */
    { 0x6, 0, 0, 0x00040000 },    /* ret      #262144    */
    { 0x6, 0, 0, 0x00000000 },    /* ret      #0         */
};
```

**BPF (Berkeley Packet Filter)**:

```text
BPF is the Linux kernel's packet filter:
- runs in kernel space
- filters network packets efficiently
- cuts the work in user space

What the PTP BPF filter does:
1. accepts only PTP messages (EtherType 0x88F7)
2. separates event messages from general messages
3. filters out messages we sent ourselves
4. supports VLAN encapsulation

Filter logic:
- check whether the EtherType is PTP (0x88F7)
- check the message class (event/general)
- check whether the source MAC is ours (avoid loopback)
- return: accept (262144) or reject (0)
```

**Reading the BPF instructions**:

```text
The inline comments already give each instruction's job. What follows only fixes the jt/jf counting, which is easy to misread:

jt/jf count how many instructions to skip, not a target line number.
The source comment (raw.c:113-129) uses tcpdump's absolute numbering.
The conversion: absolute target = current idx + 1 + jt (or jf).

idx 1  jeq #0x8100  jt 0  jf 5   with a VLAN tag, fall through to idx2; without one, jump to idx7
idx 3  jeq #0x88f7  jt 0  jf 12  after the VLAN tag it still has to be PTP, otherwise jump to idx16 (ret #0, reject)
idx 6  jeq #0x8     jt 9  jf 4   bit3=1 (general message) jump to idx16 and reject; bit3=0 (event message) jump to idx11 to check the source MAC
idx 10 jeq #0x8     jt 5  jf 0   the same test on the no-VLAN branch: jt jumps to idx16 and rejects, jf jumps to idx11
idx 14 jeq #0xdead  jt 1  jf 0   source MAC is ours: jt jumps to idx16 and rejects; jf jumps to idx15 and accepts
idx 15 ret #262144 (0x40000, accept); idx 16 ret #0 (reject)

The logic:
1. check for a VLAN tag
2. find the real EtherType
3. decide whether it is PTP
4. decide whether it is an event message
5. check the source MAC to avoid loopback
```

### raw_configure: configure the filter

```c

static int raw_configure(int fd, int event, int index,
                         unsigned char *local_addr, unsigned char *addr1,
                         unsigned char *addr2, int enable)
{
    int err1, err2, option;
    struct packet_mreq mreq;
    struct sock_fprog prg;

    /* step 1: install the BPF filter (the "rewrite source MAC" patch is applied in the event/general branches) */
    if (event) {
        prg.len = ARRAY_SIZE(raw_filter_vlan_norm_event);
        prg.filter = raw_filter_vlan_norm_event;

        memcpy(&prg.filter[FILTER_EVENT_POS_SRC0].k, local_addr, 2);      /* raw.c:166 */
        memcpy(&prg.filter[FILTER_EVENT_POS_SRC2].k, local_addr + 2, 4);
        prg.filter[FILTER_EVENT_POS_SRC0].k =
            ntohs(prg.filter[FILTER_EVENT_POS_SRC0].k);
        prg.filter[FILTER_EVENT_POS_SRC2].k =
            ntohl(prg.filter[FILTER_EVENT_POS_SRC2].k);
    } else {
        prg.len = ARRAY_SIZE(raw_filter_vlan_norm_general);
        prg.filter = raw_filter_vlan_norm_general;

        memcpy(&prg.filter[FILTER_GENERAL_POS_SRC0].k, local_addr, 2);    /* raw.c:176 */
        memcpy(&prg.filter[FILTER_GENERAL_POS_SRC2].k, local_addr + 2, 4);
        prg.filter[FILTER_GENERAL_POS_SRC0].k =
            ntohs(prg.filter[FILTER_GENERAL_POS_SRC0].k);
        prg.filter[FILTER_GENERAL_POS_SRC2].k =
            ntohl(prg.filter[FILTER_GENERAL_POS_SRC2].k);
    }

    if (setsockopt(fd, SOL_SOCKET, SO_ATTACH_FILTER, &prg, sizeof(prg))) {
        pr_err("setsockopt SO_ATTACH_FILTER failed: %m");
        return -1;
    }

    /* step 2: join the multicast group */
    option = enable ? PACKET_ADD_MEMBERSHIP : PACKET_DROP_MEMBERSHIP;

    memset(&mreq, 0, sizeof(mreq));
    mreq.mr_ifindex = index;
    mreq.mr_type = PACKET_MR_MULTICAST;
    mreq.mr_alen = MAC_LEN;
    memcpy(mreq.mr_address, addr1, MAC_LEN);

    err1 = setsockopt(fd, SOL_PACKET, option, &mreq, sizeof(mreq));
    if (err1)
        pr_warning("setsockopt PACKET_MR_MULTICAST failed: %m");    /* raw.c:199 */

    memcpy(mreq.mr_address, addr2, MAC_LEN);

    err2 = setsockopt(fd, SOL_PACKET, option, &mreq, sizeof(mreq));
    if (err2)
        pr_warning("setsockopt PACKET_MR_MULTICAST failed: %m");    /* raw.c:205 */

    if (!err1 && !err2)
        return 0;

    /* step 3: if multicast fails, try all-multicast (these modes take no MAC address, so mr_alen must be zero) */
    mreq.mr_ifindex = index;
    mreq.mr_type = PACKET_MR_ALLMULTI;
    mreq.mr_alen = 0;
    if (!setsockopt(fd, SOL_PACKET, option, &mreq, sizeof(mreq))) {
        return 0;
    }
    pr_warning("setsockopt PACKET_MR_ALLMULTI failed: %m");         /* raw.c:216 */

    /* step 4: if that still fails, try promiscuous mode */
    mreq.mr_ifindex = index;
    mreq.mr_type = PACKET_MR_PROMISC;
    mreq.mr_alen = 0;
    if (!setsockopt(fd, SOL_PACKET, option, &mreq, sizeof(mreq))) {
        return 0;
    }
    pr_warning("setsockopt PACKET_MR_PROMISC failed: %m");          /* raw.c:224 */

    pr_err("all socket options failed");
    return -1;
}
```

**Three levels of fallback**:

```text
The multicast fallback strategy:

Level 1: PACKET_MR_MULTICAST
- join the given multicast MAC addresses
- receive only PTP multicast
- most efficient

Level 2: PACKET_MR_ALLMULTI
- receive every multicast frame
- PTP and everything else
- a little less efficient, but compatible

Level 3: PACKET_MR_PROMISC
- promiscuous mode, receive every frame
- multicast and unicast
- least efficient, but it always works

Why fall back?
- some NICs don't support a specific multicast address
- some drivers have bugs
- promiscuous mode keeps the link usable
```

### raw_recv: receive an Ethernet frame

```c
/* raw.c, lines 407-446 */

static int raw_recv(struct transport *t, int fd, void *buf, int buflen,
                    struct address *addr, struct hw_timestamp *hwts)
{
    struct raw *raw = container_of(t, struct raw, t);
    unsigned char *ptr = buf;
    struct eth_hdr *hdr;
    int cnt, hlen;

    /* work out the header length */
    if (raw->vlan) {
        hlen = sizeof(struct vlan_hdr);   /* 18 bytes */
    } else {
        hlen = sizeof(struct eth_hdr);    /* 14 bytes */
    }

    /* move the buffer pointer */
    ptr -= hlen;           /* reserve room for the header */
    buflen += hlen;        /* enlarge the buffer */
    hdr = (struct eth_hdr *) ptr;

    /* receive the Ethernet frame */
    cnt = sk_receive(fd, ptr, buflen, addr, hwts, MSG_DONTWAIT);

    if (cnt >= 0)
        cnt -= hlen;       /* return the PTP message length */
    if (cnt < 0)
        return cnt;

    /* handle the PRP trailer */
    if (has_prp_trailer(buf, cnt))
        cnt -= PRP_TRAILER_LEN;

    /* detect VLAN and update the state */
    if (raw->vlan) {
        if (ETH_P_1588 == ntohs(hdr->type)) {
            pr_notice("raw: disabling VLAN mode");
            raw->vlan = 0;
        }
    } else {
        if (ETH_P_8021Q == ntohs(hdr->type)) {
            pr_notice("raw: switching to VLAN mode");
            raw->vlan = 1;
        }
    }

    return cnt;
}
```

**Dynamic VLAN detection**:

```text
VLAN encapsulation:

An ordinary Ethernet frame:
┌─────────┬─────────┬─────────┬─────────────┐
│Dst MAC  │Src MAC  │0x88F7   │PTP Message  │
│6 bytes  │6 bytes  │2 bytes  │N bytes      │
└─────────┴─────────┴─────────┴─────────────┘

A VLAN-tagged frame:
┌─────────┬─────────┬─────────┬─────────┬─────────┬─────────────┐
│Dst MAC  │Src MAC  │0x8100   │TCI      │0x88F7   │PTP Message  │
│6 bytes  │6 bytes  │2 bytes  │2 bytes  │2 bytes  │N bytes      │
└─────────┴─────────┴─────────┴─────────┴─────────┴─────────────┘

raw->vlan state:
- 0: normal mode, hlen=14
- 1: VLAN mode, hlen=18

Dynamic detection:
- check the EtherType on every received frame
- switch modes to match reality
- adapt to the network on its own
```

### PRP (Parallel Redundancy Protocol)

```c
/* raw.c, lines 297-346 */

static bool has_prp_trailer(unsigned char *ptr, int cnt)
{
    unsigned short suffix_id, lane_size_field, lsdu_size;
    int ptp_msg_len, trailer_start;
    struct ptp_header *hdr;

    /* check for a valid PTP message */
    if (cnt < sizeof(struct ptp_header))
        return false;

    hdr = (struct ptp_header *)ptr;
    if ((hdr->ver & MAJOR_VERSION_MASK) != PTP_MAJOR_VERSION)
        return false;

    ptp_msg_len = ntohs(hdr->messageLength);
    if (cnt < (ptp_msg_len + PRP_TRAILER_LEN))
        return false;

    trailer_start = cnt - PRP_TRAILER_LEN;

    /* check the RCT trailer */
    lane_size_field = ntohs(*(unsigned short*)(ptr + trailer_start + 2));
    lsdu_size = lane_size_field & 0x0FFF;
    if (lsdu_size != cnt)
        return false;

    suffix_id = ntohs(*(unsigned short*)(ptr + trailer_start + 4));
    if (suffix_id == ETH_P_PRP) {
        return true;
    }

    return false;
}
```

**The PRP redundancy protocol**:

```text
PRP (IEC 62439-3):
- two networks in parallel
- both carry the same frame at the same time
- the receiver discards duplicates

The PRP trailer (RCT):
┌───────────┬───────────┬───────────┐
│SeqNr      │LanId+Size │Suffix     │
│16 bits    │16 bits    │16 bits    │
└───────────┴───────────┴───────────┘

Suffix: 0x88FB (the PRP EtherType)
The RCT is six bytes.

PTP over PRP:
- a PTP frame carries the PRP trailer
- the receive path strips it
- cnt -= PRP_TRAILER_LEN
```

## Socket helper functions

### sk_receive: one path for send and receive

```c
/* sk.c, lines 418-508 */

int sk_receive(int fd, void *buf, int buflen,
               struct address *addr, struct hw_timestamp *hwts, int flags)
{
    char control[256];
    int cnt = 0, res = 0, level, type;
    struct cmsghdr *cm;
    struct iovec iov = { buf, buflen };
    struct msghdr msg;
    struct timespec *sw, *ts = NULL;

    /* set up the message structure */
    memset(control, 0, sizeof(control));
    memset(&msg, 0, sizeof(msg));
    if (addr) {
        msg.msg_name = &addr->ss;
        msg.msg_namelen = sizeof(addr->ss);
    }
    msg.msg_iov = &iov;
    msg.msg_iovlen = 1;
    msg.msg_control = control;
    msg.msg_controllen = sizeof(control);

    /* for a transmit timestamp, poll first (sk.c:439-459) */
    if (flags == MSG_ERRQUEUE) {
        struct pollfd pfd = { fd, sk_events, 0 };
        res = poll(&pfd, 1, sk_tx_timeout);
        /* Retry once on EINTR to avoid logging errors before exit */
        if (res < 0 && errno == EINTR)
            res = poll(&pfd, 1, sk_tx_timeout);
        if (res < 0) {
            pr_err("poll for tx timestamp failed: %m");
            return -errno;
        } else if (!res) {
            pr_err("timed out while polling for tx timestamp");
            pr_err("increasing tx_timestamp_timeout or increasing "
                   "kworker priority may correct this issue, "
                   "but a driver bug likely causes it");
            errno = ETIME;
            return -1;
        } else if (!(pfd.revents & sk_revents)) {
            pr_err("poll for tx timestamp woke up on non ERR event");
            return -1;
        }
    }

    /* receive the message */
    cnt = recvmsg(fd, &msg, flags);
    if (cnt < 0) {
        pr_err("recvmsg%sfailed: %m",
               flags == MSG_ERRQUEUE ? " tx timestamp " : " ");
    }

    /* parse the control messages (timestamps) */
    for (cm = CMSG_FIRSTHDR(&msg); cm != NULL; cm = CMSG_NXTHDR(&msg, cm)) {
        level = cm->cmsg_level;
        type  = cm->cmsg_type;
        if (SOL_SOCKET == level && SO_TIMESTAMPING == type) {
            if (cm->cmsg_len < sizeof(*ts) * 3) {    /* short message check, sk.c:470-473 */
                pr_warning("short SO_TIMESTAMPING message");
                return -EMSGSIZE;
            }
            ts = (struct timespec *) CMSG_DATA(cm);
        }
        if (SOL_SOCKET == level && SO_TIMESTAMPNS == type) {
            if (cm->cmsg_len < sizeof(*sw)) {        /* short message check, sk.c:477-480 */
                pr_warning("short SO_TIMESTAMPNS message");
                return -EMSGSIZE;
            }
            sw = (struct timespec *) CMSG_DATA(cm);
            hwts->sw = timespec_to_tmv(*sw);
        }
    }

    if (addr)
        addr->len = msg.msg_namelen;

    if (!ts) {
        memset(&hwts->ts, 0, sizeof(hwts->ts));
        return cnt < 0 ? -errno : cnt;
    }

    /* pick the timestamp by type */
    switch (hwts->type) {
    case TS_SOFTWARE:
        hwts->ts = timespec_to_tmv(ts[0]);    /* software timestamp */
        break;
    case TS_HARDWARE:
    case TS_ONESTEP:
    case TS_P2P1STEP:
        hwts->ts = timespec_to_tmv(ts[2]);    /* hardware timestamp */
        break;
    case TS_LEGACY_HW:
        hwts->ts = timespec_to_tmv(ts[1]);    /* legacy hardware timestamp */
        break;
    }

    return cnt < 0 ? -errno : cnt;
}
```

### sk_timestamping_init: configure timestamping

```c

int sk_timestamping_init(int fd, const char *device, enum timestamp_type type,
                         enum transport_type transport, int vclock)
{
    int err, filter1, filter2 = 0, flags, tx_type = HWTSTAMP_TX_ON;
    struct so_timestamping timestamping;

    /* step 1: work out the timestamp flags */
    switch (type) {
    case TS_SOFTWARE:
        flags = SOF_TIMESTAMPING_TX_SOFTWARE |
                SOF_TIMESTAMPING_RX_SOFTWARE |
                SOF_TIMESTAMPING_SOFTWARE;
        break;
    case TS_HARDWARE:
    case TS_ONESTEP:
    case TS_P2P1STEP:
        flags = SOF_TIMESTAMPING_TX_HARDWARE |
                SOF_TIMESTAMPING_RX_HARDWARE |
                SOF_TIMESTAMPING_RAW_HARDWARE;
        break;
    case TS_LEGACY_HW:
        flags = SOF_TIMESTAMPING_TX_HARDWARE |
                SOF_TIMESTAMPING_RX_HARDWARE |
                SOF_TIMESTAMPING_SYS_HARDWARE;
        break;
    default:
        return -1;
    }

    /* step 2: hardware timestamping needs driver configuration */
    if (type != TS_SOFTWARE) {
        filter1 = HWTSTAMP_FILTER_PTP_V2_EVENT;
        switch (type) {
        case TS_SOFTWARE:            /* sk.c:591-593: the outer test already excludes TS_SOFTWARE, so this branch is unreachable */
            tx_type = HWTSTAMP_TX_OFF;
            break;
        case TS_HARDWARE:
        case TS_LEGACY_HW:
            tx_type = HWTSTAMP_TX_ON;
            break;
        case TS_ONESTEP:
            tx_type = HWTSTAMP_TX_ONESTEP_SYNC;
            break;
        case TS_P2P1STEP:
            tx_type = HWTSTAMP_TX_ONESTEP_P2P;
            break;
        }

        switch (transport) {
        case TRANS_UDP_IPV4:
        case TRANS_UDP_IPV6:
            filter2 = HWTSTAMP_FILTER_PTP_V2_L4_EVENT;
            break;
        case TRANS_IEEE_802_3:
            filter2 = HWTSTAMP_FILTER_PTP_V2_L2_EVENT;
            break;
        case TRANS_DEVICENET:        /* sk.c:613-617: the three industrial transports and UDS don't use hardware timestamping */
        case TRANS_CONTROLNET:
        case TRANS_PROFINET:
        case TRANS_UDS:
            return -1;
        }

        err = hwts_init(fd, device, filter1, filter2, tx_type);
        if (err)
            return err;
    }

    /* step 3: bind the virtual clock */
    if (vclock >= 0)
        flags |= SOF_TIMESTAMPING_BIND_PHC;

    timestamping.flags = flags;
    timestamping.bind_phc = vclock;

    /* step 4: enable timestamping */
    if (setsockopt(fd, SOL_SOCKET, SO_TIMESTAMPING,
                   &timestamping, sizeof(timestamping)) < 0) {
        pr_err("ioctl SO_TIMESTAMPING failed: %m");
        return -1;
    }

    /* step 5: configure the error queue */
    flags = 1;
    if (setsockopt(fd, SOL_SOCKET, SO_SELECT_ERR_QUEUE,
                   &flags, sizeof(flags)) < 0) {
        pr_warning("%s: SO_SELECT_ERR_QUEUE: %m", device);
        sk_events = 0;
        sk_revents = POLLERR;
    }

    /* step 6: enable SO_TIMESTAMPNS when needed (sk.c:643-647; body in sk.c:165-173) */
    /* Enable the sk_check_fupsync option, perhaps. */
    if (sk_general_init(fd)) {
        return -1;
    }

    return 0;
}
```

**Hardware timestamp configuration**:

```text
The SIOCSHWTSTAMP ioctl:

struct hwtstamp_config {
    int flags;       /* configuration flags */
    int tx_type;     /* transmit timestamp type */
    int rx_filter;   /* receive timestamp filter */
};

tx_type:
HWTSTAMP_TX_OFF: no transmit timestamp
HWTSTAMP_TX_ON: ordinary hardware timestamp
HWTSTAMP_TX_ONESTEP_SYNC: one-step clock (Sync messages)
HWTSTAMP_TX_ONESTEP_P2P: one-step clock (P2P messages)

rx_filter:
HWTSTAMP_FILTER_NONE: no receive timestamp
HWTSTAMP_FILTER_PTP_V2_L2_EVENT: Ethernet PTP
HWTSTAMP_FILTER_PTP_V2_L4_EVENT: UDP PTP
HWTSTAMP_FILTER_PTP_V2_EVENT: all PTP
HWTSTAMP_FILTER_ALL: every packet
```

## Unix-domain sockets (UDS)

### What UDS is for

```text
UDS (Unix Domain Socket):
- local inter-process communication
- never touches the network
- used for the management interface

Uses:
- pmc talks to ptp4l
- sends management messages
- reads clock information
- changes settings

UDS is not a PTP network transport!
- it is only a management interface
- it takes no part in PTP synchronization
- transport_type=0 (a reserved value)
```

### UDS path configuration

```c
/* uds.c, lines 53-103 */

static int uds_open(struct transport *t, struct interface *iface, 
                    struct fdarray *fda, enum timestamp_type tt)
{
    char *uds_ro_path = config_get_string(t->cfg, NULL, "uds_ro_address");
    const char *uds_path = interface_remote(iface);
    struct uds *uds = container_of(t, struct uds, t);
    const char *name = interface_name(iface);
    const char* file_mode_cfg;
    struct sockaddr_un sa;
    mode_t file_mode;
    int fd, err;

    /* create the socket */
    fd = socket(AF_LOCAL, SOCK_DGRAM, 0);
    if (fd < 0) {                                        /* uds.c:66-69 */
        pr_err("uds: failed to create socket: %m");
        return -1;
    }

    /* bind the path */
    memset(&sa, 0, sizeof(sa));
    sa.sun_family = AF_LOCAL;
    strncpy(sa.sun_path, name, sizeof(sa.sun_path) - 1);

    /* remove an existing file */
    if (!unlink(name))
        pr_err("uds: removed existing %s", name);

    /* bind */
    err = bind(fd, (struct sockaddr *) &sa, sizeof(sa));
    if (err < 0) {                                       /* uds.c:78-82 */
        pr_err("uds: bind failed: %m");
        close(fd);
        return -1;
    }

    /* set the file mode: the read-only UDS has its own setting (uds.c:84-88) */
    file_mode_cfg = "uds_file_mode";
    // The RO UDS socket has a separate configuration for file mode
    if (0 == strncmp(name, uds_ro_path, MAX_IFNAME_SIZE))
        file_mode_cfg = "uds_ro_file_mode";
    file_mode = (mode_t)config_get_int(t->cfg, name, file_mode_cfg);

    /* For client use, pre load the server path. */        /* uds.c:90-97 */
    memset(&sa, 0, sizeof(sa));
    sa.sun_family = AF_LOCAL;
    if (uds_path) {
        strncpy(sa.sun_path, uds_path, sizeof(sa.sun_path) - 1);
    }
    uds->address.sun = sa;
    uds->address.len = sizeof(sa);

    chmod(name, file_mode);

    fda->fd[FD_EVENT] = -1;
    fda->fd[FD_GENERAL] = fd;
    return 0;
}
```

**Default UDS paths**:

```text
Configuration defaults:

uds_address: /var/run/ptp4l
- created by ptp4l for management
- pmc connects to this path

uds_ro_address: /var/run/ptp4lro
- read-only interface
- lets non-root users read

File mode:
uds_file_mode: 0660
- user and group can read and write

Example:
pmc -u -s /var/run/ptp4l "GET CURRENT_DATA_SET"
```

## Summary: the design wisdom of the transport layer

**The abstract interface**:
- one transport interface
- several transports, all called through the same table
- upper layers don't care which transport is underneath

**UDP transport**:
- ports 319/320
- multicast address configuration
- DSCP priority

**Raw Ethernet**:
- EtherType 0x88F7
- BPF filter
- VLAN support

**Timestamp configuration**:
- SO_TIMESTAMPING
- SIOCSHWTSTAMP
- software and hardware timestamping

**UDS management**:
- local communication
- the pmc tool's interface
