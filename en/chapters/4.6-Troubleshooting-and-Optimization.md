# 4.6 Troubleshooting and Optimization

## Common problems

### Problem 1: no messages arrive

```bash
# check: firewall
sudo iptables -A INPUT -p udp --dport 319 -j ACCEPT
sudo iptables -A INPUT -p udp --dport 320 -j ACCEPT

# check: multicast route
ip maddr show eth0
# you should see the multicast address
```

Open both ports: 319 is event (Sync, Delay_Req), 320 is general (Follow_Up, Announce, Delay_Resp). If you open only 319, the slave sits at `Received Sync seq=N` forever, never getting a `Follow_Up`. The symptom is one `DROP: Delay_Resp without a complete Sync/Delay_Req round (total N)` every second (`ptp_slave.c:413-416`).

### Problem 2: time is off

```bash
# check: system clock
timedatectl status
# turn off NTP: timedatectl set-ntp false
```

`systemd-timesyncd`, `chronyd`, and `ntpd` all modify the same `CLOCK_REALTIME` as ptp_lite. The NTP daemons take their own slew or step paths; ptp_lite uses `clock_settime` plus `ADJ_FREQUENCY` (`ptp_slave.c:305`, `:260`). Two loops that don't know about each other pull in opposite directions. The offset wanders around some non-zero value for long stretches, and the sign on `FREQ ADJ` keeps flipping. Check whether another process is fighting you:

```bash
ps -eo pid,cmd | grep -E 'chronyd|systemd-timesyncd|ntpd' | grep -v grep
```

### Problem 3: large offset

```text
# cause: software timestamping has poor precision
# fix: use hardware timestamping (the NIC must support it)
```

## Performance optimization

> ⚠️ The code below is **illustrative; the repository does not implement it**.

```c
#include <sched.h>

/* example 1: raise priority (needs CAP_SYS_NICE, or a higher RLIMIT_RTPRIO) */
struct sched_param param;
param.sched_priority = 99;                  /* the highest SCHED_FIFO priority */
if (sched_setscheduler(0, SCHED_FIFO, &param) < 0) {
    perror("sched_setscheduler");           /* EPERM: an ordinary user can't get real-time scheduling */
}

/* example 2: CPU affinity (pinned to core 2 here; in practice it depends on the machine's topology and interrupt layout) */
cpu_set_t cpuset;
CPU_ZERO(&cpuset);
CPU_SET(2, &cpuset);
sched_setaffinity(0, sizeof(cpuset), &cpuset);

/* optimization 3: timestamping clock source */
/* the timestamp must be on the same timescale as the clock being disciplined
clock_gettime(CLOCK_REALTIME, ...) */
```
